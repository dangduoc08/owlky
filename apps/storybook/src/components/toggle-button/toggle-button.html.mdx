## Anatomy

```html
<div role="group" data-mt-toggle-group data-mt-orientation="horizontal" data-mt-exclusive aria-label="Text alignment">
  <button type="button" data-mt-toggle-button data-mt-color="inherit" data-mt-size="md"
          value="left" aria-pressed="true" aria-label="Left">…</button>
  …
</div>

<!-- Standalone -->
<button type="button" data-mt-toggle-button data-mt-color="primary" data-mt-size="md" aria-pressed="false">…</button>
```

## Events and API

```js
group.addEventListener("mt:toggle-group:change", (event) => {
  const { value, previous, button } = event.detail; // value: string | null (exclusive) or string[]
  if (!allowed(value)) event.preventDefault(); // keeps the current selection
});
button.addEventListener("mt:toggle-button:change", (event) => event.detail.pressed);

const runtime = getRuntime();
runtime.get(group, "toggle-group").setValue(["bold"]); // no event
runtime.get(button, "toggle-button").setPressed(true); // no event
```
