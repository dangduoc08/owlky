## Anatomy

| Element | Role |
|---|---|
| `label[data-mt-switch]` | Root; `data-mt-color` (`primary`…`error`), `data-mt-size` (`sm` · `md`) |
| `input[type=checkbox][role=switch][data-mt-switch-input]` | The control — use `checked`, `disabled`, `name`, `value` as usual |
| `span[data-mt-switch-track]` › `span[data-mt-switch-thumb]` | Visuals, `aria-hidden="true"` |
| `span[data-mt-switch-label]` | Optional visible label (the accessible name) |

## Accessibility

- Announced as a **switch** with on/off state; the label (or `aria-label`) is its name.
- **Space** toggles; focus ring shows on the track (`:focus-visible`).
- The visible label is part of the `<label>`, so clicking it toggles the switch.
