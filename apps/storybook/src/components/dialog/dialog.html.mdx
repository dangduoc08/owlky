# Dialog — HTML

Copy-paste markup, wired up automatically by the **Core Runtime** through `data-mt-*` attributes.
No custom JavaScript needed.

## Requirements

| | |
|---|---|
| CSS | `minimal-tailwind.css` — or `tokens.css` + `components/dialog.css` (+ `components/button.css` for the buttons) |
| JavaScript | **Core Runtime required** — `minimal-tailwind.js`, included once per page |
| Browsers | Native `showModal()`; an automatic fallback is used where it is missing (see ADR-0006) |

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@minimal-tailwind/html@0/dist/minimal-tailwind.css">
<script src="https://cdn.jsdelivr.net/npm/@minimal-tailwind/html@0/dist/minimal-tailwind.js" defer></script>
```

Without the runtime, the dialog stays closed (it is a native `<dialog>`) — the page never shows a half-working component.

## Attributes

| Attribute | On | Purpose |
|---|---|---|
| `data-mt-dialog` | `<dialog id>` | Root. Mounted automatically, also when inserted later. |
| `data-mt-size` | root | `xs` (444px) · `sm` (600px, default) · `md` · `lg` · `full` |
| `data-mt-dialog-open="<id>"` | any button | Opens the dialog with that id |
| `data-mt-dialog-close` | button inside | Closes its dialog (or `="<id>"` from anywhere) |
| `data-mt-escape-close="false"` | root | Ignore Escape |
| `data-mt-backdrop-close="false"` | root | Ignore clicks outside the content |
| `data-mt-open` | root | Open on page load |
| `data-mt-dialog-content` / `-title` / `-body` / `-actions` | parts | Layout |

## JavaScript API (optional)

```js
const dialog = MinimalTailwind.get(document.getElementById("confirm-dialog"), "dialog");
dialog.open();        // false if prevented
dialog.close();

document.getElementById("confirm-dialog").addEventListener("mt:dialog:beforeclose", (event) => {
  if (event.detail.reason === "backdrop") event.preventDefault(); // cancelable
});
```

Events (bubbling): `mt:dialog:beforeopen` (cancelable) · `mt:dialog:open` ·
`mt:dialog:beforeclose` (cancelable, `detail.reason`) · `mt:dialog:close` (`detail.reason`:
`escape` · `backdrop` · `trigger` · `api` · `native`).

## Keyboard

| Key | Action |
|---|---|
| `Tab` / `Shift+Tab` | Moves focus within the dialog; the page behind is inert |
| `Escape` | Closes (unless `data-mt-escape-close="false"`) |

## Accessibility

- Give the dialog a name: `aria-labelledby` → the title's `id` (or `aria-label`). `aria-describedby` for supporting text.
- On open, focus goes to the `[autofocus]` element, else the first focusable element, else the content.
- On close, focus returns to the trigger. The page cannot be scrolled or focused while open.
- Only the topmost dialog reacts to Escape and backdrop clicks — also across React and HTML on the same page.
