## Accessibility

- Use a real `<button type="button">` (or `<a href>` for navigation) so keyboard and screen-reader support is native.
- Icon wrappers are decorative: `aria-hidden="true"`. An icon-only button needs `aria-label`.
- `disabled` removes the button from the tab order. Use `aria-disabled="true"` to keep it focusable (e.g. to explain why in a tooltip) — then block the action in your own handler.
- Focus is shown with a 2px outline (`:focus-visible`). Text colors meet WCAG 2.2 AA in light and dark themes.
