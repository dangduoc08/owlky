## Anatomy

```html
<button type="button" data-mt-icon-button data-mt-color="primary" data-mt-size="md" aria-label="Mail">
  <svg aria-hidden="true" …></svg>
</button>
```

| Attribute | Values | Default |
|---|---|---|
| `data-mt-icon-button` | — (required) | |
| `data-mt-color` | `default` · `inherit` · `primary` · `secondary` · `info` · `success` · `warning` · `error` · `black` · `white` | `default` |
| `data-mt-size` | `sm` (28px) · `md` (36px) · `lg` (48px) | `md` |
| `data-mt-animate` | — (boolean): scale on hover / press | off |

## Accessibility

Name every icon button with `aria-label` (the icon is `aria-hidden`). Spec:
`specs/components/icon-button.md`.
