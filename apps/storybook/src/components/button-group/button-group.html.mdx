## Anatomy

```html
<div role="group" data-mt-button-group data-mt-orientation="horizontal" aria-label="Pages">
  <button type="button" data-mt-button data-mt-variant="outlined" data-mt-color="primary" data-mt-size="md">
    <span data-mt-button-label>One</span>
  </button>
  …
</div>
```

The group only joins its buttons; write `data-mt-variant` / `data-mt-color` / `data-mt-size` (and
`disabled`) on every button. `data-mt-orientation`: `horizontal` (default) · `vertical`. Spec:
`specs/components/button-group.md`.
