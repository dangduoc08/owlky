# @minimal-tailwind/react

Accessible React components for [Minimal Tailwind](../../README.md). React 18.3+ / 19.

> Status: foundations first (ADR-0011). Components are added here one by one, each shipped
> together with its HTML implementation. The package currently exports shared types only.

```sh
pnpm add @minimal-tailwind/react @minimal-tailwind/styles
```

```tsx
import "@minimal-tailwind/styles/minimal-tailwind.css";
```

Same markup and CSS as `@minimal-tailwind/html`.
