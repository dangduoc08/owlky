# Toggle button

Reference: Minimal UI kit "Buttons" page, section "Toggle button" (content only). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/buttons

## Purpose
A button that stays pressed (format text, choose a view). Standalone, or in a group with
exclusive (one) or multiple selection.

## Anatomy
```
div[role="group"][data-ok-toggle-group][data-ok-orientation][data-ok-exclusive]?[aria-label]
  button[type="button"][data-ok-toggle-button][data-ok-color][data-ok-size][value][aria-pressed]…
    svg[aria-hidden="true"] | text

button[type="button"][data-ok-toggle-button]…[aria-pressed]      (standalone)
```

React passes the group's `color`, `size` and `disabled` to every child (a child prop wins).

## States
- Unpressed: secondary text color. Pressed: bg `channel` 8 % and `main` text (standard:
  `--ok-action-selected`, primary text); standalone pressed buttons also get a `currentColor` border.
- Standalone: 1px border (grey 20 %). Group: 1px border (grey 16 %), 4px padding and gap; buttons inside
  have no border.
- `:hover` (`hover: hover`): `--ok-action-hover` (colored: `channel` 8 %). `:disabled`:
  `--ok-action-disabled` text; pressed + disabled: `--ok-action-disabled-bg` fill.

## Behavior
Runtime needed in HTML (React keeps state). Selection logic is shared in core
(`nextToggleSelection()`): exclusive → pressing the pressed button clears the selection, any other
replaces it; multiple → adds or removes the value. Disabled buttons never change.

## Keyboard
Native buttons: `Tab` to each button, `Enter` / `Space` toggle.

## Accessibility
`aria-pressed` carries the state; the group is `role="group"` (add `aria-label`). Icon-only buttons
need `aria-label`.

## Events / API
HTML, cancelable (call `preventDefault()` to keep the current state):
- `ok:toggle-button:change` on a standalone button — `detail: { pressed }` (the new state).
- `ok:toggle-group:change` on the group — `detail: { value, previous, button }` (`value` shaped as
  in the options table).

Instances: `runtime.get(el, "toggle-button")` → `{ pressed, setPressed(pressed) }`;
`runtime.get(el, "toggle-group")` → `{ value, setValue(value) }` (setters don't emit events).
React: `onChange(selected)` on a standalone `ToggleButton`, `onChange(value)` on `ToggleButtonGroup`;
both work controlled and uncontrolled.

## Responsive
Same size at every breakpoint; use `vertical` for narrow screens.

## Upstream API mapping
Upstream: MUI `ToggleButton`, `ToggleButtonGroup`, mui.com/material-ui/api/toggle-button/ and
/toggle-button-group/.

| Upstream | Owlky | Status | Note |
|---|---|---|---|
| ToggleButton `children`, `value`, `selected`, `color`, `disabled`, `fullWidth`, `onClick` | same | kept | `onClick` native; + `defaultSelected` (uncontrolled) |
| ToggleButton `size` (`small` · `medium` · `large`) | `size` (`sm` · `md` · `lg`) | renamed | |
| ToggleButton `onChange(event, value)` | `onChange(selected)` | renamed | value-first (ADR-0015) |
| ToggleButtonGroup `children`, `exclusive`, `value`, `orientation`, `fullWidth`, `color`, `disabled` | same | kept | + `defaultValue`; exclusive value `string \| null` |
| ToggleButtonGroup `size` | `size` (`sm` · `md` · `lg`) | renamed | |

| `disableRipple`, `disableFocusRipple` (+ ButtonBase ripple props) | — | not applicable | no ripple |
| `sx`, `classes` | — | not applicable | ADR-0015 |

## Parity notes
React renders `data-ok-runtime="off"` on the group and on standalone buttons.
