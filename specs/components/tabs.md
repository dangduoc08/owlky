# Tabs

Reference: Minimal UI kit "Tabs" page, sections Text, Icon, Colors, Scrollable, Vertical, Custom
(content only). Upstream: MUI `Tabs` / `Tab`, `TabPanel` from MUI Lab (ADR-0015). Created with
`/component`.
Reference URL: https://minimals.cc/components/mui/tabs

## Purpose
Switch between related views on one page (WAI-ARIA tabs pattern). A sliding indicator marks the
selected tab. Behavior is core `createTabsController` (keyboard, indicator, scroll buttons),
shared by React and the HTML runtime `tabs`; the owner applies the selection.

## Anatomy
```
div[data-ok-tabs][data-ok-variant][data-ok-orientation][data-ok-text-color][data-ok-indicator-color][data-ok-scroll-buttons]…
  div[data-ok-tabs-scroll-button="start"][aria-hidden="true"] › svg      (scrollable, scrollButtons ≠ false)
  div[data-ok-tabs-scroller]
    div[role="tablist"][data-ok-tabs-list][aria-label | aria-labelledby][aria-orientation="vertical"]?
      button[type="button"][role="tab"][data-ok-tab][data-ok-icon-position]?[data-ok-wrapped]?
            [value][aria-selected][tabindex][id]?[aria-controls]?[disabled]?
        svg[aria-hidden="true"]? span[data-ok-tab-label]?
    span[data-ok-tabs-indicator]                     (--_ok-tabs-indicator-start / -size via CSSOM)
  div[data-ok-tabs-scroll-button="end"][aria-hidden="true"] › svg
div[role="tabpanel"][data-ok-tab-panel][id][aria-labelledby][tabindex="0"][hidden]?   (one per tab)
```

## Layout and tokens
Tabs: `min-height` 48px (`spacing × 12`), `min-width` 48px, padding 12px 0, gap 40px
(`spacing × 10`; `fullWidth`, vertical and segmented: 0), `subtitle2` size / line height, weight
`--ok-font-weight-medium`, selected `--ok-font-weight-semibold`. Colors: unselected
`--ok-text-secondary`, selected `--ok-text-primary` (or primary / secondary `main`). Icon 24px;
top / bottom: 72px tall, 9px padding, 6px gap; start / end: row, 8px gap. Disabled: opacity 0.48.
Indicator: 2px (`--ok-text-primary` or palette `main`), slides over `--ok-duration-standard`
(after the first measure: `data-ok-ready`). Segmented: bar `--ok-bg-neutral`, `--ok-radius-md`,
list padding 0 8px (vertical 8px 0), tabs 52px tall, padding-inline 16px; indicator `::after` pill
inset 6px, `--ok-bg-paper`, `--ok-shadow-z1`, `--ok-radius-md`. Scroll buttons 40px wide,
opacity 0.8 (0 at an edge).

## States
`aria-selected="true"` (selected), `:focus-visible` (2px `--ok-text-primary` outline, inset),
`:disabled`. Controller flags: `data-ok-can-scroll-start` / `-end` on the root (scroll buttons),
`data-ok-ready` on the indicator.

## Behavior
- Click / Enter / Space on an unselected, enabled tab → `onSelect` intent; the owner selects
  (React: `onChange`; HTML: `ok:tabs:change`, then `aria-selected`, `tabindex`, panels' `hidden`).
- Arrow keys move focus only (manual activation, MUI default); `selectionFollowsFocus` selects on
  focus. Disabled tabs are skipped.
- Indicator: measured from the selected tab's offset box (ResizeObserver + `document.fonts.ready`
  re-measure). No selection → zero size.
- Scrollable: the scroller scrolls (scrollbar hidden unless `visibleScrollbar`); scroll buttons
  page by the scroller's size (smooth unless reduced motion); a newly selected tab scrolls into
  view (scroller only). `scrollButtons="auto"`: hidden without overflow and below 600px (unless
  `allowScrollButtonsMobile`); `true`: always; `false`: not rendered.

## Keyboard
| Key | Action |
|---|---|
| Tab | Into the list (selected tab, else the first enabled one), then to the panel |
| → / ← (vertical ↓ / ↑) | Next / previous enabled tab, wrapping (mirrored in RTL) |
| Home / End | First / last enabled tab |
| Enter / Space | Select the focused tab |

## Accessibility
`role="tablist"` named by `aria-label` / `aria-labelledby`; `aria-orientation="vertical"` when
vertical; tabs `role="tab"` with `aria-selected` and roving `tabindex`; `aria-controls` ↔ panel
`aria-labelledby`; panels `tabindex="0"`. Scroll buttons are `aria-hidden` pointer aids (the arrow
keys reach every tab). Brand-colored selected text (primary / secondary) is exempt from
`color-contrast` (ADR-0014); unselected text is AA.

## Events / API
HTML `ok:tabs:change` (cancelable) — `detail: { value, previous, tab }`. Instance
`runtime.get(el, "tabs")` → `{ value, setValue(value), select(tab) }` (`setValue` emits nothing).
React: `onChange(value)`; controlled and uncontrolled.

## Responsive
Same size at every breakpoint. Scrollable bars hide their scroll buttons below 600px (`auto`);
standard bars clip, so use `scrollable` for many tabs on phones.

## Parity notes
React renders `data-ok-runtime="off"`. Controller-written state (`style`, `data-ok-ready`,
`data-ok-can-scroll-*`) is the same in both (same controller). Parity ignores `style`.
