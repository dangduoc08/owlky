# Button

Reference: Minimal UI kit "Buttons" page (content only). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/buttons

## Purpose
Trigger an action (`<button>`) or navigate (`<a href>`) with the button styling.

## Anatomy
```
(button[type="button"] | a[href])[data-ok-button][data-ok-variant][data-ok-color][data-ok-size]
    [data-ok-full-width]? [data-ok-loading][data-ok-loading-position][aria-busy="true"][disabled]?
  span[data-ok-button-icon="start"][aria-hidden="true"]?  › svg[aria-hidden="true"]
  span[data-ok-button-loader][aria-hidden="true"]?        › span[data-ok-button-spinner] | text
  span[data-ok-button-label]                              (always; carries the accessible name)
  span[data-ok-button-icon="end"][aria-hidden="true"]?    › svg[aria-hidden="true"]
```
Visual order is set by CSS `order`: start icon, loader (start), label, loader (end), end icon.
Default loader: a Circular progress (`specs/components/circular-progress.md`),
`span[data-ok-circular-progress][data-ok-variant="indeterminate"][data-ok-color="inherit"][data-ok-button-spinner]`,
sized 16px by `button.css` (CSS only, no runtime needed). An empty `span[data-ok-button-spinner]`
(earlier markup) still renders as a CSS ring.

Other props (not options):

| HTML | React | Values |
|---|---|---|
| loader content | `loadingIndicator` | spinner or text (e.g. `Loading…`) |
| `<a href>` | `href` | URL, passed through untouched |
| icon wrappers | `startIcon` / `endIcon` | ReactNode |

React renders all modifiers explicitly (`buttonAttributes()`); unknown values fall back to the
defaults in both `buttonAttributes()` and CSS. `disabled` (or `loading`) on a link removes `href`
and sets `aria-disabled="true"`.

## Tokens
Radius `--ok-radius-md`; heights and paddings are multiples of `--ok-spacing`; font
`--ok-font-size-sm|md|lg` + `--ok-typography-button-*`; colors through the `--ok-c-*` bindings,
with `--ok-c-channel` for translucent fills (`rgb(var(--…-channel) / α)` — never `color-mix()` in
component CSS); hover shadow `--ok-c-shadow` (`--ok-shadow-z8` for inherit / black / white).

| Variant | Rest | Hover (`hover: hover` only) |
|---|---|---|
| contained | bg `main`, text `contrast` | bg `hover` (`dark`; 72 % for black/white) + `--ok-c-shadow` |
| outlined | border `channel` 48 % (inherit: grey-500 32 %), text `main` | bg 8 %, border `currentColor` + 0.75px ring |
| text | text `main` | bg 8 % |
| soft | bg `channel` 16 %, text `text` | bg 32 % |
| disabled | text `--ok-action-disabled`; bg `--ok-action-disabled-bg` (contained / soft) or border (outlined) | — |

## Responsive
Same size per `data-ok-size` at every breakpoint; labels don't wrap (`nowrap`); rows of buttons
wrap. Use `fullWidth` for full-width mobile actions. Every size is ≥ 24×24 CSS px (WCAG 2.5.8).

## Behavior
Native element only — **CSS only, no runtime**. Loading uses native `disabled` (approved
decision): the button leaves the tab order while loading.

## Keyboard
Native: `Enter` / `Space` activate a button; `Enter` follows a link.

## Accessibility
- Name = label text. Icons and the loader are `aria-hidden`; while loading in the center the
  label is made transparent, never hidden, so the name stays. Icon-only buttons need `aria-label`.
- `aria-busy="true"` while loading; 2px focus outline (`:focus-visible`), offset 2px.
- Colors follow the reference (ADR-0014): white on `main` fills (dark on warning), `main` text
  for outlined / text; soft uses the AA `-text` tone. `black` / `white` are for light / dark
  surfaces.

## Events / API
None: CSS only, no runtime. React forwards `ref` (`HTMLButtonElement`, or `HTMLAnchorElement` with
`href`) and every native button / link prop.

## Differences from the reference (intentional)
Visible focus outline (the reference has none); loader wrapper `aria-hidden` + `aria-busy` (the
loader is a `progressbar`, as on the reference, but hidden from assistive technology); "Link" is a real `<a href>`;
consistent sizes across variants (the reference's soft `sm` / `lg` differ slightly); black / white
shown on matching surfaces. Colors match the reference (ADR-0014); strict AA is an opt-in override.

## Not included (separate components)
