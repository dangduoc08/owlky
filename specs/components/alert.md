# Alert

Reference: Minimal UI kit "Alert" page — Standard, Filled, Outlined, Description, Actions (content
only). Upstream: MUI Alert (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/alert

## Purpose
A short, important message with a severity.

## Anatomy
```
div[role="alert"][data-ok-alert][data-ok-severity][data-ok-variant][data-ok-color]
  div[data-ok-alert-icon] › svg[aria-hidden="true"]          (omit with icon={false})
  div[data-ok-alert-message]
    div[data-ok-alert-title]?                                 (AlertTitle)
    … message
  div[data-ok-alert-action]?
    … your actions (Buttons) | button[data-ok-icon-button][data-ok-alert-close][aria-label="Close"]
```

Other props (React): `icon` (node, `false` hides it), `iconMapping`, `action`, `onClose` (renders
the close button), `closeText` (`"Close"`), `role` (`"alert"`). HTML: write the icon and buttons in
the markup; the runtime handles `[data-ok-alert-close]`.

## Layout and tokens
- Padding 6px 16px, `--ok-radius-md`, `--ok-typography-body2-*`; icon 24px with 12px gap, message
  padding 8px 0, title `--ok-typography-subtitle1-*`.
- `standard`: background `lighter`, text `darker` (dark scheme: background `darker`, text `lighter`,
  via `light-dark()`; older browsers keep the light look), icon `main`.
- `filled`: background `main`, text `contrastText`, weight medium.
- `outlined`: background `main` 8 %, border `main` 16 %, text `dark`, icon `main`.

## Behavior
CSS only, except the close button: the HTML runtime emits `ok:alert:close` (cancelable) and then
hides the alert (`hidden`). React calls `onClose`; you stop rendering the alert.

## Accessibility
`role="alert"` by default (announced on insertion — use `role="status"` for non-urgent messages).
Icons are `aria-hidden`; the close button is named by `closeText`. Filled and outlined colors follow
the reference (ADR-0014): exempt from axe `color-contrast` only.

## Events / API
HTML: `ok:alert:close` (cancelable); instance `close()`. React: `onClose`.

## Responsive
Full width; the message wraps, actions stay at the end.
