# Rating

Reference: Minimal UI kit "Rating" page, sections Controlled, Read only, Disabled, Custom icon and
color, 10 stars, Hover feedback, Half ratings, Sizes (content only). Upstream: MUI `Rating`
(ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/rating

## Purpose
Give or show a score as icons. A native radio group carries the value, keyboard and labels;
the owner (React state, HTML runtime `rating`) marks filled icons.

## Anatomy
```
span[data-ok-rating][data-ok-size][data-ok-color][data-ok-highlight-selected-only]?[data-ok-disabled]?
  span[data-ok-rating-item]                                       (one per whole value)
    label[data-ok-rating-icon][for][data-ok-value][data-ok-fraction]?[data-ok-filled]?[data-ok-hover]?
      svg[aria-hidden] | span[data-ok-rating-icon-filled] + span[data-ok-rating-icon-empty]
      span[data-ok-rating-label-text]                              (visually hidden: "2 Stars")
    input[type=radio][data-ok-rating-input][id][name][value]       (visually hidden)
  label[data-ok-rating-empty][for] + input[type=radio][data-ok-rating-input][value=""]   ("Empty")
read-only: span[data-ok-rating][data-ok-read-only][role=img][aria-label] › items › span[data-ok-rating-icon]
```
Fractions (precision 0.5 / 0.25) come first in their item, absolutely positioned over the whole
icon and clipped to `data-ok-fraction` × the size.

## Layout and tokens
Icon size `--_ok-rating-size`: 12 / 16 / 20 / 24 / 28px (`spacing` × 3 … 7). Filled: palette
`main` (default `--ok-palette-warning-main`); empty `rgb(grey-500 / 0.48)`. Solid SVGs take
`fill: currentColor`; line icons (`fill="none"`) keep their stroke. Hover: the icon under the
pointer scales 1.2 (`--ok-duration-shortest`; none with reduced motion). Disabled: opacity 0.48.
Focus: 2px `--ok-text-primary` outline around the focused value's icon.

## Behavior
Filled = value ≤ shown (hover ?? value); `highlightSelectedOnly`: = shown. A pointer click on the
current value clears it (`event.detail > 0`, so Space doesn't). Hover reports the value under the
pointer (`null` on leave). An empty fraction icon is hidden (its whole icon shows the empty state).

## Keyboard
Native radio group: Tab to the checked radio; arrows change the value, down to "Empty".

## Accessibility
Every value labelled (`getLabelText`); read-only = `role="img"` named by the value; icons
`aria-hidden`.

## Events / API
HTML `ok:rating:change` (cancelable, `{ value, previous }`; prevented → previous radio checked
again), `ok:rating:active` (`{ value }`). Instance `{ value, setValue(value) }`.

## Responsive
Same sizes everywhere; 24px icons meet the 24px target size (smaller sizes: read-only use).
