# Timeline

Reference: Minimal UI kit "Timeline" page, sections Left, Right, Alternating, Filled, Outlined,
Opposite content, Customized (content only). Upstream: MUI Lab `Timeline` parts (ADR-0015).
Created with `/component`.
Reference URL: https://minimals.cc/components/mui/timeline

## Purpose
Events in order along a vertical line. CSS only (no runtime).

## Anatomy
```
ul[data-ok-timeline][data-ok-position]
  li[data-ok-timeline-item][data-ok-position]?
    div[data-ok-timeline-opposite-content]?
    div[data-ok-timeline-separator]
      span[data-ok-timeline-dot][data-ok-variant][data-ok-color] › svg[aria-hidden]?
      span[data-ok-timeline-connector]?            (not on the last item)
    div[data-ok-timeline-content]
```

## Layout and tokens
Root padding 6px 16px, list reset. Item: flex row (left: row-reverse), min-height 70px; without
opposite content a `::before` takes the other half (MUI). Content / opposite: `flex: 1`, padding
6px 16px, body1, `overflow-wrap: anywhere`; content aligned away from the line, opposite toward it.
Dot: 4px padding + 2px border (12px), margin 11.5px 0, `--ok-palette-grey-400` (grey), palette
`main`, `--ok-text-primary` (inherit); outlined: border in the color, transparent fill; an icon is
24px (36px dot). Connector: 2px, `--ok-divider`, grows. Alternate: even items reversed
(`alternate-reverse`: odd).
