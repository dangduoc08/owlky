# Form control label

Reference: Minimal UI kit "Checkbox" and "Switch" pages, sections Sizes, Placement(s), Colors
(content only). Upstream: MUI `FormControlLabel` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/checkbox

## Purpose
A `<label>` around a control (Checkbox, Switch; Radio later) and its text: the text names the
control and clicking it toggles the control.

## Anatomy
```
label[data-ok-form-control-label][data-ok-label-placement][data-ok-required]?
  (control: span[data-ok-checkbox] | span[data-ok-switch])
  span[data-ok-form-control-label-text]
    …label
    span[data-ok-form-control-label-asterisk][aria-hidden="true"]?   (required)
```

## Options

| React | HTML | Kind | Values | Default | Description |
|---|---|---|---|---|---|
| `labelPlacement` | `data-ok-label-placement="…"` | style | `end` `start` `top` `bottom` | `end` | Where the text sits around the control. |
| `required` | `data-ok-required` | flag | boolean | off | Shows an asterisk; the control gets `required`. |
<!-- /options:form-control-label -->

React: `control` (element), `label` (node); `disabled`, `required`, `checked`, `onChange`,
`value` are cloned onto the control when set and the control doesn't set them (server-safe
`cloneElement`). Upstream `disableTypography`, `slots`, `slotProps`, `sx`, `classes` don't apply.

## Layout and tokens
Body2 text (`--ok-typography-body2-*`), `--ok-text-primary`; margin −11px on the control side
(`--ok-spacing` × −2.75) and 16px (× 4) on the other; `start` reverses the row, `top` / `bottom`
stack (margin 16px on both inline sides). Disabled (`:has(input:disabled)`): `--ok-text-disabled`.

## Responsive behavior
Inline-flex; text wraps (`overflow-wrap: anywhere`) instead of overflowing.

## Keyboard / Accessibility
Native `<label>`: the text is the control's accessible name; clicking it toggles. The asterisk is
hidden from assistive technology (the input is `required`).

## Events / API
None (the control's events).
