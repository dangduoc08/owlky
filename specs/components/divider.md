# Divider

Reference: MUI "Divider" demo page, sections Variants, Orientation, Flex item, With children, Icon
grouping (content only; Minimals has no Divider page — its Drawer page uses MUI's Divider).
Upstream: MUI `Divider` (ADR-0015). Created with `/component`.
Reference URL: https://mui.com/material-ui/react-divider/

## Purpose
A thin line that groups content. CSS only.

## Anatomy
```
hr[data-ok-divider][data-ok-variant][data-ok-orientation][aria-orientation="vertical"]?[data-ok-flex-item]?[data-ok-absolute]?
div[role=separator][aria-orientation][data-ok-divider][…][data-ok-text-align]? › span[data-ok-divider-text]   (with children)
```

React: `children` (text or a node, e.g. a Chip). Not applicable: `component` (the element follows
the content: `hr`, or `div role="separator"` with children), `light` (deprecated upstream: use a
token override), `sx`, `classes`, `role` (native / set by the component).

## Layout and tokens
1px `--ok-divider`; `inset` 72px start (`--ok-spacing` × 18); `middle` 16px inline (vertical: 8px
block); vertical `height: 100%`, `flexItem` stretches; `absolute` pins to the bottom. With text:
`--ok-text-secondary` body2, lines as `::before` / `::after`, text padding 10px (`left` / `right`:
the near line is 10%).

## Responsive behavior
Fluid; the text never wraps (`white-space: nowrap`).

## Keyboard / Accessibility
Not focusable. `hr` is a native separator; vertical ones carry `aria-orientation="vertical"`.

## Events / API
None.
