# Radio

Reference: Minimal UI kit "Radio button" page, sections Basic, Sizes, Placement, Colors (content
only). Upstream: MUI `Radio`, `RadioGroup` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/radio-button
Color picker (single): Minimal UI kit "Utilities" page, section Color pickers › Single
(https://minimals.cc/components/extra/utilities, roadmap 4.23; upstream: the kit's own
`ColorPicker`).

## Purpose
Pick exactly one option from a short list. Native `<input type="radio">` in a `radiogroup`; the
browser keeps one checked per name and moves with the arrow keys. CSS only.

## Anatomy
```
div[role=radiogroup][data-ok-radio-group][data-ok-row]?[aria-label|aria-labelledby]
  (label[data-ok-form-control-label] ›)? span[data-ok-radio][data-ok-color][data-ok-size]
    input[type=radio][data-ok-radio-input][name][value]   (covers the target, opacity 0)
    span[data-ok-radio-icon="unchecked"][aria-hidden="true"] › span[data-ok-radio-ring]
    span[data-ok-radio-icon="checked"][aria-hidden="true"]   › span[data-ok-radio-ring]
```
Color swatch (`swatch`): the icons give way to one swatch.
```
span[data-ok-radio][data-ok-color][data-ok-size][data-ok-swatch=<css color>][data-ok-shape]?
  input[type=radio][data-ok-radio-input][aria-label=<color name>]
  span[data-ok-radio-swatch][aria-hidden="true"] › svg[data-ok-icon="check-linear"] (shown while checked)
```
React `ref` and the remaining props go to the input (`RadioGroup`: the group element);
`className` / `style` to the root span. Swatch colors are user data, not tokens: they reach CSS as
`--_ok-swatch` (and the mark color `--_ok-swatch-mark`) through React `style` or the HTML `radio`
runtime (CSSOM); snippets never carry `style`.

Swatch options: `swatch` (React prop; HTML `data-ok-swatch`, free text so not in the schema): a
CSS color (`#hex`, `rgb()` / `hsl()` / `oklch()`…, a named color) or a `var(--ok-…)` token;
anything else (`url(`, `;`, braces, quotes, longer than 64 characters, or refused by
`CSS.supports`) is dropped and the swatch shows grey. `shape` only applies to swatches.

React: `RadioGroup` `name` (default `useId()`), `value` / `defaultValue` / `onChange(value)`;
`Radio` `value`, `icon` / `checkedIcon`, standalone `onChange(checked)`. Upstream `disableRipple`,
`sx`, `classes`, `slots`, `slotProps` don't apply.

## Layout and tokens
Swatches (`[data-ok-swatch]`): target 36px (× 9; `small` 28px, × 7), swatch 20px (× 5; `small`
16px), checked 28px (× 7; `small` 20px) with `--ok-shadow-z8` and a check mark (`--ok-icon` 60% of
the swatch) in white or pure black, whichever contrasts more with a `#hex` / `rgb()` color (white
for other formats); a 1px inset ring `--ok-palette-grey-500-channel` at 0.16 keeps light colors
visible; `circular` (radio default) `--ok-radius-full`, `rounded` (checkbox default)
`--ok-radius-sm`; hover `--ok-action-hover` on the target; focus-visible 2px `--ok-text-primary`
ring around the swatch (offset 2px); disabled at 0.48 opacity; forced colors keep the swatch
color (`forced-color-adjust: none`) and draw a `CanvasText` ring on the checked one.

Same as Checkbox: target 40 / 36px, icon 24 / 20px; the default ring is CSS (83% of the icon,
`--ok-radius-full`, a border of `--ok-icon-stroke` px; checked: a dot of 56%, `::before`), unchecked `--ok-text-secondary`, checked
`--ok-c-main` (`default` = `--ok-text-primary`), disabled `--ok-action-disabled`, hover main
channel at 0.08, focus-visible 2px `currentColor` ring inside the target. Group: flex column;
`row` → row, wrapping.

## Responsive behavior
Fixed control size; rows wrap.

## States / Behavior
From the input via `:has()`: `:checked`, `:disabled`, `:focus-visible`. Native selection.
Swatches: checked = larger swatch + check mark + shadow (never color alone). HTML runtime
`radio` (swatches only): writes `--_ok-swatch` / `--_ok-swatch-mark` from `data-ok-swatch`
(core `swatchStyle`), again when it changes. Without the runtime a swatch shows grey; selection
still works.

## Keyboard
| Key | Action |
|---|---|
| Tab | Focus the group (its checked radio) |
| Arrow keys | Select the next / previous radio |
| Space | Select the focused radio |

## Accessibility
`role="radiogroup"` named by the author; each radio named by its label. Swatches name each
input with the color's name (`aria-label="Orange"`), not only its code. Brand colors follow the
reference (ADR-0014).

## Events / API
HTML: native `change`. React: `RadioGroup` `onChange(value)`; standalone `Radio` `onChange(checked)`.

## Parity notes
None. The Colors story wraps the group in a `fieldset` FormControl with a `legend` FormLabel
