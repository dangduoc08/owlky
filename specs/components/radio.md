# Radio

Reference: Minimal UI kit "Radio button" page, sections Basic, Sizes, Placement, Colors (content
only). Upstream: MUI `Radio`, `RadioGroup` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/radio-button

## Purpose
Pick exactly one option from a short list. Native `<input type="radio">` in a `radiogroup`; the
browser keeps one checked per name and moves with the arrow keys. CSS only.

## Anatomy
```
div[role=radiogroup][data-ok-radio-group][data-ok-row]?[aria-label|aria-labelledby]
  (label[data-ok-form-control-label] ›)? span[data-ok-radio][data-ok-color][data-ok-size]
    input[type=radio][data-ok-radio-input][name][value]   (covers the target, opacity 0)
    span[data-ok-radio-icon="unchecked"][aria-hidden="true"] › svg
    span[data-ok-radio-icon="checked"][aria-hidden="true"]   › svg
```
React `ref` and the remaining props go to the input (`RadioGroup`: the group element);
`className` / `style` to the root span.

React: `RadioGroup` `name` (default `useId()`), `value` / `defaultValue` / `onChange(value)`;
`Radio` `value`, `icon` / `checkedIcon`, standalone `onChange(checked)`. Upstream `disableRipple`,
`sx`, `classes`, `slots`, `slotProps` don't apply.

## Layout and tokens
Same as Checkbox: target 40 / 36px, icon 24 / 20px, unchecked `--ok-text-secondary`, checked
`--ok-c-main` (`default` = `--ok-text-primary`), disabled `--ok-action-disabled`, hover main
channel at 0.08, focus-visible 2px `currentColor` ring inside the target. Group: flex column;
`row` → row, wrapping.

## Responsive behavior
Fixed control size; rows wrap.

## States / Behavior
From the input via `:has()`: `:checked`, `:disabled`, `:focus-visible`. Native selection.

## Keyboard
| Key | Action |
|---|---|
| Tab | Focus the group (its checked radio) |
| Arrow keys | Select the next / previous radio |
| Space | Select the focused radio |

## Accessibility
`role="radiogroup"` named by the author; each radio named by its label. Brand colors follow the
reference (ADR-0014).

## Events / API
HTML: native `change`. React: `RadioGroup` `onChange(value)`; standalone `Radio` `onChange(checked)`.
