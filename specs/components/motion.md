# Motion

Reference: Minimal UI kit "Animate" page, tabs In View, Scroll, Dialog, Background and Other
(Tap & hover, Path, Count up, Logo, Avatar, Border) (content only). Upstream: Framer Motion
variants (`initial` / `animate` / `exit`, `whileInView`, `viewport.once` / `amount`,
`staggerChildren`, `whileHover` / `whileTap`) — mapped to CSS animations, no dependency
(ADR-0015). Created with `/component`; named Motion because `data-ok-animate` is the
IconButton / Fab hover flag.
Reference URL: https://minimals.cc/components/extra/animate

## Purpose
Entrance and exit animations for any content (Motion), staggered groups (MotionGroup), letter by
letter text (MotionText), looping backgrounds (Ken Burns, pan, color change), SVG stroke drawing,
hover / press scaling, counters (CountUp) and turning gradient borders (MotionBorder). The CSS plays
the animations; core decides when (`createMotionTrigger`: mount, in view, manual) and counts
(`createCountUp`). Without JavaScript nothing is hidden: the start state needs `data-ok-state`.

```
  [data-ok-duration]?[data-ok-delay]?[data-ok-distance]?[data-ok-paused]?[data-ok-state=initial|enter|exit]
  › content (draw: an svg whose shapes have pathLength="1")
[data-ok-motion-group][trigger options][data-ok-stagger]? › [data-ok-motion]…   (direct children staggered)
span[data-ok-motion-text][data-ok-variant][trigger options][data-ok-stagger]?[data-ok-state]
  › span[data-ok-motion-text-label] (visually hidden text)
  + span[aria-hidden=true] › span[data-ok-motion-text-word] › span[data-ok-motion-char]…
span[data-ok-count-up][data-ok-end][data-ok-start]?[data-ok-decimals]?[data-ok-duration]?[trigger options]
  › span[data-ok-count-up-label] (visually hidden end value) + span[aria-hidden=true] › prefix,
    span[data-ok-count-up-value], suffix
div[data-ok-motion-border][data-ok-shape][data-ok-color][data-ok-width]?[data-ok-duration]?[data-ok-paused]? › content
Dialog: div[data-ok-dialog-paper][data-ok-motion][data-ok-variant][data-ok-trigger=mount]   (`transition`)
```
Private properties (React `style`, HTML CSSOM): `--_ok-motion-duration | -delay | -distance |
-stagger | -index`, `--_ok-motion-border-width | -duration | -fill`.

Content: `children` (MotionText: a string), CountUp `prefix` / `suffix`. API mapping (Framer
Motion): variants → `variant` (the reference's 48 entrance / exit names, its background and its
other effects); `whileInView` + `viewport.once` / `amount` → `trigger="inView"`, `once`, `amount`;
`animate` / `exit` / `AnimatePresence` → `trigger="manual"` + `in` (exits play the entrance
backwards); `transition.duration` / `delay` → `duration`, `delay`; `staggerChildren` → MotionGroup /
MotionText `stagger`; `whileHover` / `whileTap` → `variant="interactive"`; `pathLength` → `draw`.
Beyond the reference: `paused` (WCAG 2.2.2). Deferred: `component` (Motion always renders a
`div`), spring physics, custom keyframes, layout animations, scroll-linked progress (Scroll
progress page), exit of a Dialog. Not applicable: `motion.*` element factories, `useAnimate`.

## Layout and tokens
Entrances: `--ok-duration-enter` (640ms), exits `--ok-duration-exit` (480ms),
`--ok-easing-expressive`. Distances: 160px (`--ok-spacing` × 40) slides, 120px fades, 360px
directional zoom / bounce. Loops: `--ok-duration-enter` × 8 (≈ 5 s). Draw: × 3. Interactive:
scale 1.09 on hover, 0.97 pressed, `--ok-duration-shorter`. Color change: a gradient of primary,
warning, secondary and error `main`, 2–5 times the text width (the element shrinks to its content).
MotionBorder: 2px, `--ok-radius-lg` (circle: 50%), conic gradient (multi: the same four colors;
a palette color: that color sweeping), inside painted with `--ok-bg-paper`
(`--_ok-motion-border-fill`). CountUp: tabular figures, ease-out cubic, 2000ms.

## Behavior
`initial` holds in-variants at their start (paused animation) and out-variants as themselves;
`enter` plays; `exit` plays the other way (other keyframe name, so it restarts). An entered
in-variant drops the animation at its end (`animation-fill-mode: backwards`): no transform is left.
`inView` (IntersectionObserver; none → shown at once): plays when `amount` is visible; `once=false`
exits when it leaves. `mount`: at once. `manual`: follows `in` / `data-ok-in`. Changing `variant`,
`duration` or `distance` replays an entered Motion (React too). MotionGroup drives every Motion
whose closest group it is. Loops run while entered, `paused` stops them. Reduced motion: entrances
and exits take 1ms, loops and the border don't run, interactive doesn't transition, CountUp shows
the end at once.

## Keyboard
Not interactive. Content inside keeps its own keyboard behavior.

## Accessibility
Content never depends on the animation (no JavaScript → shown; reduced motion → shown at once).
MotionText and CountUp hide the moving copy (`aria-hidden`) and expose a visually hidden label with
the whole text / end value. Loops need a pause control (WCAG 2.2.2): `paused`. Directional
entrances start outside the box: clip containers that could widen the page.

## Events / API
HTML: `ok:motion:end` (`{ state }`) on a Motion. Instances: motion / motion-group / motion-text
`{ state, replay() }`, count-up `{ replay() }`, motion-border `{}` (width and duration only).
React: native `onAnimationEnd`; change the `key` to replay.

## Responsive
Nothing changes per breakpoint. Stories clip their stages (`overflow: clip`).

## Parity notes
React renders `data-ok-runtime="off"` and writes `data-ok-state` itself (SSR: `initial`); snippets
carry no state (the runtime writes it). React 19's `<link rel="preload">` hints next to images are
skipped by parity. Private properties go through `style` (ignored by parity).
