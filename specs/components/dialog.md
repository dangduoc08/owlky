# Dialog

Reference: Minimals "Dialog" page, sections Simple, Alerts, Transitions, Form, Full-screen,
Max width, Scrolling content (content only). Upstream: MUI `Dialog`, `DialogTitle`,
`DialogContent`, `DialogContentText`, `DialogActions` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/dialog

## Purpose
A modal surface. Runtime behavior: core `createModalController` (shared with Drawer: native
`showModal()`, fallback with inert siblings, focus trap and return, scroll lock, layer stack).

## Anatomy
```
button[data-ok-dialog-open="id"][aria-haspopup=dialog]
dialog[data-ok-dialog][id][aria-labelledby][data-ok-max-width][data-ok-scroll]…
  › div[data-ok-dialog-paper]
      › h2[data-ok-dialog-title][id]
      › div[data-ok-dialog-content][data-ok-dividers]? › p[data-ok-dialog-content-text]?
      › div[data-ok-dialog-actions][data-ok-disable-spacing]? › … [data-ok-dialog-close]
```

React: `open` / `onOpenChange(open, reason)` (escape | backdrop | close), `paperProps`; the title
names the dialog automatically (`aria-labelledby`, unless `aria-label` is given). Parts:
`DialogContent dividers`, `DialogActions disableSpacing`. Renamed: `onClose(event, reason)` →
`onOpenChange`; `PaperProps` → `paperProps`; `maxWidth={false}` → `"none"`. Deferred:
`TransitionComponent` (one opening animation; the reference's Slide), `keepMounted` (always
mounted). Not applicable: `slots`, `slotProps`, `sx`, `BackdropComponent` (native `::backdrop`,
`--ok-backdrop`, the Backdrop component's token: a DOM Backdrop can't sit between a top-layer
`<dialog>` and its `::backdrop`), `disablePortal` (top layer).

## Layout and tokens
Paper: radius `--ok-radius-xl`, `--ok-shadow-dialog`, `--ok-bg-paper`, margin 16px (32px from
600px), max height viewport − 2 × margin; widths xs 444px, sm 600px, md/lg/xl the breakpoint
tokens. Title h6 (600) padding 24px; content padding 0 24px (dividers: 16px + 1px lines); content
text `--ok-text-secondary` body1; actions padding 24px, gap 12px. Full screen: no margin, radius,
shadow. Backdrop `--ok-backdrop`. Opening: fade + scale 0.96 (`--ok-duration-short`).

## Responsive behavior
Mobile-first margin (16px → 32px at 600px); the paper never exceeds the viewport.

## Keyboard / Accessibility
Native modal: inert page, Tab trapped, Escape → `onOpenChange(false, "escape")` (unless
`disableEscapeKeyDown`), backdrop click (press and release outside the paper). Focus: first tabbable
or `[autofocus]`, else the paper; returns to the trigger. Scrollable content gets
`tabindex="0"` + a name in the stories.

## Events / API
HTML: `ok:dialog:beforeopen` (cancelable), `ok:dialog:open`, `ok:dialog:beforeclose` (cancelable,
`detail.reason`: escape | backdrop | trigger | api), `ok:dialog:close` (also `native`). Instance:
`{ isOpen, open(trigger?), close(reason?) }`. `data-ok-open` opens on load.
