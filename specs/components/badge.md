# Badge

Reference: Minimal UI kit "Badge" page, sections Standard, Dot, Status, Maximum value, Badge overlap
(content only). Upstream: MUI `Badge` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/badge

## Purpose
A count, dot or presence status on the corner of an icon, avatar or text. CSS only.

## Anatomy
```
span[data-ok-badge][data-ok-variant][data-ok-color][data-ok-overlap][data-ok-vertical][data-ok-horizontal][data-ok-invisible]?
  (the anchor element)
  span[data-ok-badge-badge] › count | text | span[data-ok-avatar] | (empty: dot and statuses)
```

## Layout and tokens
Standard: 20px high, min 20px, padding 0 6px, `--ok-radius-full`, 12px medium; dot 8px; statuses
10px with a 2px `--ok-bg-paper` ring (online success, always warning + clock hand, busy error +
bar, offline ring `--ok-text-disabled`, invisible hidden). Default grey-300 / text-primary; colors
`--ok-c-main` / `--ok-c-contrast`. Center on the corner: translate(±50%); circular overlap 14% in.
Hiding scales to 0 (`--ok-duration-shorter`). An avatar as content loses the pill.

## Behavior
None (CSS). HTML authors write the displayed text ("99+") and `data-ok-invisible`.

## Keyboard / Accessibility
Not focusable. The count is visible text: the author names the anchor with the meaning
("4 new messages"); dots and statuses are visual only.

## Events / API
None.
