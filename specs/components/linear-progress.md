# Linear progress

Reference: Minimal UI kit "Progress" page, section "Linear" (Indeterminate, Determinate, Buffer,
Query; content only). Upstream: MUI `LinearProgress` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/progress

## Purpose
A thin bar for work of unknown length (indeterminate, query) or that shows how far a task has got
(determinate) and how far loading has got (buffer).

## Anatomy
```
span[data-ok-linear-progress][role=progressbar][aria-label|aria-labelledby]
    [data-ok-variant][data-ok-color]
    [aria-valuenow][aria-valuemin][aria-valuemax]   (determinate, buffer)
    [data-ok-value-buffer]?                         (buffer)
  span[data-ok-linear-progress-dashed]              buffer only
  span[data-ok-linear-progress-bar="1"]
  span[data-ok-linear-progress-bar="2"]             indeterminate, query, buffer
```
The track is the root's `::before`. React renders `data-ok-runtime="off"` on the root.

Upstream `color` lists inherit / primary / secondary (+ theme colors); every palette color is
offered, as on the reference. `sx` / `classes` don't apply. Numbers are validated as for Circular
progress; the buffer is clamped to the range.

## Layout and tokens
- Height 4px (`--ok-spacing`), width 100% of the container (`min-width: 0`), radius
  `--ok-radius-full`, `overflow: hidden`.
- Color: `--ok-c-main` (fallback primary), `inherit` = text color; parts paint with
  `currentColor`: track opacity 0.24, buffer bar 0.24, dots 0.48 (radial gradient, 10px tile =
  `--ok-spacing` × 2.5). Opacity instead of channels, so `inherit` works.
- Private properties (React `style`, HTML runtime CSSOM): `--_ok-progress-value`,
  `--_ok-progress-buffer` (0–1). Bars: `translateX((fraction − 1) × 100%)`, transition
  `--ok-duration-standard` linear.
- Indeterminate: bar 1 / bar 2 sweep with `left` / `right` keyframes, 2.1s, bar 2 delayed 1.15s.
  Query = indeterminate rotated 180°. Buffer dots drift (3s). Choreography constants, not tokens.
- Reduced motion: sweeps at 4.2s (delay 2.3s), dots still, no value transition.

## Responsive behavior
Fills its container at every breakpoint; no breakpoint rules. Stories stack the bars in a column.
"With label" (MUI's demo) composes a Typography (`body2`, `textSecondary`) beside the bar; there
is no label part.

## States
`data-ok-variant` only. Not focusable.

## Behavior
CSS only in React. HTML runtime (`linear-progress`): on mount and whenever `data-ok-variant`,
`aria-valuenow`, `aria-valuemin`, `aria-valuemax` or `data-ok-value-buffer` change, writes the
private properties; `destroy` removes them. Changing the variant doesn't add or remove parts:
the markup must match the variant (see Anatomy).

## Keyboard
None (not focusable).

## Accessibility
`role="progressbar"`, named by the author. Determinate / buffer: `aria-valuenow` (clamped),
`aria-valuemin`, `aria-valuemax`; the buffer is visual only. `aria-valuetext` passes through.
Brand colors follow the reference (ADR-0014). Right to left: under `dir="rtl"` the root is
mirrored (`scale: -1 1`, `:dir(rtl)`; without `:dir()` support, a `[dir="rtl"]` ancestor or the
bar's own `dir`), so every variant fills from the right.

## Events / API
None. HTML: change the attributes above. React: props; `ref` = the root span.

## Scroll progress
`scroll` (React) / `data-ok-scroll-progress` and its `data-ok-scroll-*` options (HTML): the bar follows a scroll position instead of a value,
decorative (`aria-hidden`), determinate by default. See `specs/components/scroll-progress.md`
(Motion 5.2, ADR-0062).
