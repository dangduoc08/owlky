# Slider

Reference: Minimal UI kit "Slider" page, sections Volume, Disabled, Temperature, Sizes, Small steps,
Custom marks, Restricted values, Range, Vertical, Colors (content only). Upstream: MUI `Slider`
(ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/slider

## Purpose
Pick a value or a range on a track. Each thumb holds a native `input[type=range]` (keyboard
events, screen readers, forms); core `createSliderController` handles pointer drags and keys and
reports intent; the owner (React state, HTML runtime `slider`) applies values.

## Anatomy
```
span[data-ok-slider][data-ok-color][data-ok-size][data-ok-orientation][data-ok-track][data-ok-value-label-display]
    [data-ok-min]?[data-ok-max]?[data-ok-step]?[data-ok-disabled]?[data-ok-disable-swap]?[data-ok-label-value]?
  span[data-ok-slider-rail]
  span[data-ok-slider-track]                                 (--_ok-slider-start / -end)
  span[data-ok-slider-mark][data-ok-value][data-ok-active]?   (--_ok-slider-at)
  span[data-ok-slider-mark-label][data-ok-value][aria-hidden]
  span[data-ok-slider-thumb][data-ok-index][data-ok-active]?   (--_ok-slider-at)
    input[type=range][min][max][step][value][aria-label|aria-labelledby][aria-valuetext]?[aria-orientation]?[name]?
    span[data-ok-slider-value-label][aria-hidden]?
```
Positions are private custom properties (React `style`; HTML runtime CSSOM). Snippets carry none.

## Layout and tokens
Root: 26px vertical padding area (13px), width 100% (vertical: height 100%, min 100px). Rail:
10 / 6px (`spacing` × 2.5 / 1.5), `rgb(grey-500 / 0.12)`, `--ok-radius-lg`. Track: `main`.
Thumb: 20 / 16px, `--ok-palette-common-white`, 1px `rgb(grey-500 / 0.08)` border, shadow
`0 1px 2px rgb(grey-500 / 0.16)`, inner dot 62.5% `rgb(grey-500 / 0.16)`; hover / active /
focus-visible: 8px halo `rgb(main / 0.16)`; focus-visible adds a 2px outline. Marks: 1px ticks,
`rgb(grey-500 / 0.48)` (on the track: white 64%). Mark labels `--ok-font-size-sm`,
`--ok-text-secondary`. Value label: `--ok-palette-grey-800`, white, 12px semibold, `--ok-radius-md`,
4px 8px, arrow; scales in over `--ok-duration-shortest`. Disabled: grey, no pointer.

## Behavior
Press on the rail moves the closest thumb there and starts a drag (Pointer Events, captured);
`onCommit` on release. Thumbs swap when crossing (`disableSwap`: stop at the neighbour). Keys
(on the focused input, handled by the controller): arrows ± step (marks only: next mark),
Page Up / Down ± 10 steps, Home / End; RTL mirrors Left / Right. Native `input` events
(assistive technologies) are applied too.

## Keyboard
| Key | Action |
|---|---|
| → / ↑, ← / ↓ | ± one step (or to the next mark) |
| Page Up / Page Down | ± ten steps |
| Home / End | min / max |

## Accessibility
Native range inputs (`role=slider`), named per thumb; `aria-valuetext` for units;
`aria-orientation="vertical"`; mark labels `aria-hidden` (the value text carries them).
Mark label text AA (secondary text instead of the reference's disabled grey).

## Events / API
HTML `ok:slider:change` (cancelable, `{ value: number[], activeThumb }`), `ok:slider:commit`
(`{ value }`). Instance `{ value, setValue(value) }`.

## Responsive
Horizontal sliders fill their container; vertical ones its height. Pressing the track (any
width) moves a thumb, so the 20px thumb isn't the only target.
