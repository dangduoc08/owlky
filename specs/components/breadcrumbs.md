# Breadcrumbs

Reference: Minimal UI kit "Breadcrumbs" page, sections Text, With icon, Customized (content only).
Upstream: MUI `Breadcrumbs` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/breadcrumbs

## Purpose
The path from the site root to the current page, as links. CSS only, plus the HTML runtime
`breadcrumbs` for collapsing long trails (`maxItems`).

## Anatomy
```
nav[data-ok-breadcrumbs][aria-label="breadcrumb"][data-ok-max-items]?…[data-ok-expanded]?
  ol[data-ok-breadcrumbs-list]
    li[data-ok-breadcrumbs-item] › a[href] (svg[aria-hidden]? text)   (a Link: color inherit, underline hover)
    li[data-ok-breadcrumbs-separator][aria-hidden="true"] › "/" | span[data-ok-breadcrumbs-dot]
    li[data-ok-breadcrumbs-item][data-ok-breadcrumbs-collapsed]                (collapsed)
      › button[type="button"][data-ok-breadcrumbs-expand][aria-label="Show path"] › svg
    li[data-ok-breadcrumbs-item][hidden] …                                     (collapsed items)
    li[data-ok-breadcrumbs-item] › span[aria-current="page"]
```
Items compose Link (`link.md`: `data-ok-typography data-ok-link`, `color="inherit"`,
`underline="hover"`, as in MUI's demos); a plain `a` gets the same look from `breadcrumbs.css`,
which loads after `link.css`.
Collapsed order: items before, their separators, the expand item, a separator, the hidden items
(each with its following separator hidden), the items after.

## Options

Root: `data-ok-breadcrumbs`. Unknown values fall back to the default.

| React | HTML | Kind | Values | Default | Description |
|---|---|---|---|---|---|
| `maxItems` | `data-ok-max-items="…"` | number | number | `8` | More items than this collapse into an expand button. |
| `itemsBeforeCollapse` | `data-ok-items-before-collapse="…"` | number | number | `1` | Collapsed: items shown before the expand button. |
| `itemsAfterCollapse` | `data-ok-items-after-collapse="…"` | number | number | `1` | Collapsed: items shown after the expand button. |
<!-- /options:breadcrumbs -->

Other props (not options):

| HTML | React | Values |
|---|---|---|
| `li[data-ok-breadcrumbs-item]` | `children` (each child = one item) | links and the current page |
| `li[data-ok-breadcrumbs-separator]` | `separator` (default `"/"`; `<BreadcrumbsDot />`) | node |
| `data-ok-expand-text` | `expandText` (default `"Show path"`) | string |
| `aria-label` | `aria-label` (default `"breadcrumb"`) | string |

API mapping (MUI): kept `children`, `separator`, `maxItems`, `itemsBeforeCollapse`,
`itemsAfterCollapse`, `expandText`, `aria-label`. Added: `BreadcrumbsDot` (the reference's
Customized separator). Not applicable: `component`, `slots` / `slotProps` (`CollapsedIcon`: one
built-in icon), `classes`, `sx`.

## Layout and tokens
Root `--ok-text-secondary`, body2 size / line height. List: flex, wrap, gap 4px (rows) ×
16px (`spacing × 4`). Items inline-flex, gap 4px, min-height 24px (WCAG 2.5.8), `overflow-wrap:
anywhere`; icons 20px. Current page `--ok-text-primary`. Links: no underline, underline on hover
(hover-capable devices), focus ring 2px `--ok-text-primary`. Dot 4px `--ok-palette-grey-500`.
Expand button 32 × 24px, `--ok-action-hover` (hover `--ok-action-selected`), `--ok-radius-xs`.

## Behavior
More items than `maxItems` (default 8) and `itemsBeforeCollapse + itemsAfterCollapse` (default
1 + 1) below the count → collapsed (core `breadcrumbsCollapse`). The expand button shows every
item, removes itself and focuses the first revealed item (MUI). React keeps `expanded` in state;
the HTML runtime collapses plain markup on mount (markup already collapsed is kept) and expands on
click; `data-ok-expanded` marks an expanded trail in both.

## Keyboard
Native links and button: Tab, Enter; Space on the expand button.

## Accessibility
`nav` landmark named "breadcrumb" (unique labels for several trails); `ol`; separators
`aria-hidden`; current page `aria-current="page"`, not a link; decorative icons `aria-hidden`.

## Events / API
HTML `ok:breadcrumbs:expand` (cancelable). Instance `runtime.get(el, "breadcrumbs")` →
`{ collapsed, expand() }`. React: no callback (state inside).

## Responsive
Wraps onto more rows; long text wraps inside its item. Same sizes at every breakpoint.
