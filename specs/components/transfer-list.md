# Transfer list

Reference: Minimal UI kit "Transfer list" page, sections Simple, Enhanced (content only).
Upstream: the MUI "Transfer list" demo (no MUI component; ADR-0015 maps the demo's behavior).
Created with `/component`.
Reference URL: https://minimals.cc/components/mui/transfer-list

## Purpose
Move items between two lists. A composite of existing components (Scrollbar, List, Checkbox,
Button) with its layout in `transfer-list.css`; the rules are core `transferMove` / `canTransfer`
/ `toggleAll` / `sideCheckedState`. HTML runtime `transfer-list` moves the rows.

## Anatomy
```

```

Other props: `items` (`{ value, label }[]`), `left` / `right` (controlled) or `defaultLeft`,
`onChange(left, right)`, `titles` (`["Choices", "Chosen"]`), `getCountLabel(checked, total)`
(HTML `data-ok-label-count="{checked}/{total} selected"`), `buttonLabels`, `id` (prefix of the
checkbox ids).

## Layout and tokens
Panels 220px (`spacing` × 55, max 100%), `--ok-bg-paper`, `--ok-shadow-card`, `--ok-radius-xl`;
list area 200px tall (scrolls in its Scrollbar), list padding 8px 0. Rows: min 44px, padding 4px
8px, gap 4px, subtitle2 type, hover `--ok-action-hover`; the 40px checkbox gets −2px block margins.
Header: grid (checkbox spanning title + caption count), 8px padding, `--ok-divider` bottom line.
Buttons: outlined `sm`, 16px arrows. Mobile first: panels stacked, buttons in a row with arrows
turned 90°; from 600px panels side by side (gap 24px), buttons in a column.

## Behavior
Check rows; move buttons (`all-right` · `right` · `left` · `all-left`; enhanced: `right` / `left`)
move the checked (or all) rows to the end of the other list and uncheck them. Buttons that would
move nothing are disabled. Enhanced: select-all checks / clears a side, shows mixed
(`indeterminate` + `data-ok-indeterminate`), counts follow.

## Keyboard
Native: Tab through the scroll areas, checkboxes and buttons; Space toggles / presses.

## Accessibility
Scroll areas named by the titles (regions); rows labelled by their text; buttons named
("Move selected right"); select-all named "Select all choices".

## Events / API
HTML `ok:transfer-list:change` (cancelable, `{ left, right, direction }`). Instance
`{ value, move(direction) }`. React `onChange(left, right)`.

## Responsive
Stacked below 600px (no overflow at 375px), side by side above.

## Upstream API mapping

Beyond the demo: `disabled`, `buttonLabels`, `id`, HTML `move(direction)`.

## Parity notes
