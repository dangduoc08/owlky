# Link

Reference: MUI "Links" demo page, sections Basic links, Underline, Third-party routing library,
Accessibility (content only; Minimals has no Link page). Upstream: MUI `Link` (ADR-0015).
Created with `/component`.
Reference URL: https://mui.com/material-ui/react-link/
HTML source: written by us (MUI is React only).

## Purpose
A link in the theme's colors and type scale. Built on Typography: one element carries
Typography's attributes plus `data-ok-link`, and Typography's options are spread into Link's
schema (MUI's defaults differ: `variant` `inherit`, `color` `primary`). CSS only.

## Anatomy
```
a[href][data-ok-typography][data-ok-link][data-ok-variant][data-ok-color][data-ok-underline]
  [data-ok-align]?[data-ok-gutter-bottom]?[data-ok-no-wrap]?[data-ok-max-lines]?[data-ok-persistent]?
  [target][rel]?
button[type="button"][data-ok-typography][data-ok-link]…        (an action: no destination)
```
React: `a` with `href`; `<button type="button">` without `href` and `component` (MUI renders an
`a` without `href`, which can't take focus); `component` renders anything else (a router link,
`button`, `span`). HTML authors write the element.

React: `children`, `href` (passed through untouched), `target`, `rel`, `component`, `ref`, every
attribute of the element. `target="_blank"` → `rel` always holds `noopener noreferrer` (core
`linkRel`: the consumer's tokens kept, missing ones appended). HTML snippets write the `rel`.
Not applicable: `sx`, `classes`, `TypographyClasses`, `variantMapping` (a link's element is `a` /
`button` / `component`), arbitrary color strings (consumer CSS), theme default props.

## Layout and tokens
Typography's rules (font, color) plus `link.css` (loaded right after `typography.css`):
`cursor: pointer`; `inherit` → `color: inherit`. `always`: underline in `rgb(--ok-c-channel / 0.4)`
for palette colors, `currentColor` for text tones and `inherit`; hover (hover-capable devices):
`currentColor`. `hover`: underline on hover only. `none`: never. Button links lose the button's
box (no padding, border, background; `vertical-align: middle`). Focus ring: 2px
`--ok-text-primary`, offset 2px, `--ok-radius-xs`.

## Responsive behavior
Inline text; wraps with the text around it (except `noWrap`). With `maxLines` (Typography's,
the Minimals "Text max line › As link" demo) the link becomes a block box clamped to that many
lines. Same at every breakpoint.

## Keyboard
Native: Tab focuses, Enter follows a link or activates a button link, Space activates a button
link.

## Accessibility
Default `underline="always"`: links in text are distinguishable without color (axe
`link-in-text-block`). Palette colors use `main` (ADR-0014, exempt from `color-contrast` like
Typography); `textPrimary` / `textSecondary` / `inherit` on neutral text meet AA. Actions without a
destination render a `button`. New-tab links: say so in the name (`aria-label`).

## Events / API
None (native element events).

## Integrations
Breadcrumbs items are Links (`color="inherit" underline="hover"`, as in MUI's breadcrumbs demos);
`breadcrumbs.css` loads after `link.css` and keeps its own item rules (no DOM or API change).
