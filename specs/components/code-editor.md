# Code editor

Reference: the `@monaco-editor/react` demo page (an editor with Language, Theme and Options
settings, and a Diff editor), content only, plus its README (multi-model editing, validation,
`useMonaco`, `loader`). Upstream: `@monaco-editor/react` 4.7 (`Editor`, `DiffEditor`,
`useMonaco`, `loader`; ADR-0015) on Monaco Editor 0.57 (ADR-0034). Created with `/component`.
Reference URL: https://monaco-react.surenatoyan.com/
HTML source: built from Monaco Editor (`monaco-editor`, MIT; the owner's choice)

## Purpose
Source code editing with syntax highlighting, IntelliSense, validation, multiple models and a
diff view. Monaco runs in core `createCodeEditorController` / `createDiffEditorController`
(`@owlky/core/code-editor`), shared by React and the HTML runtimes; Owlky adds the frame, the
loading state, the no-JavaScript / failure fallback and themes built from the tokens.

## Anatomy
```
div[data-ok-code-editor][data-ok-status=loading|ready|error]?[data-ok-language]?[data-ok-path]?
   [data-ok-monaco-theme]?[data-ok-line]?[data-ok-width]?[data-ok-height]?[data-ok-options]?
   [data-ok-save-view-state="false"]?[data-ok-keep-current-model]?
  textarea[data-ok-code-editor-value][aria-label][spellcheck=false][autocomplete=off][autocapitalize=off][wrap=off]
  div[data-ok-code-editor-loading][role=status]       ("Loading..." or the `loading` content)
  div[data-ok-code-editor-content][class]?            (Monaco: div.monaco-editor …)
div[data-ok-diff-editor][data-ok-status]?[data-ok-language]?[data-ok-original-language]?[data-ok-modified-language]?
   [data-ok-original-model-path]?[data-ok-modified-model-path]?[data-ok-monaco-theme]?[data-ok-width]?[data-ok-height]?
   [data-ok-line]?[data-ok-options]?[data-ok-keep-current-original-model]?[data-ok-keep-current-modified-model]?
  textarea[data-ok-diff-editor-original][aria-label] + textarea[data-ok-diff-editor-modified][aria-label]
  div[data-ok-diff-editor-loading][role=status]
  div[data-ok-diff-editor-content][class]?            (Monaco: div.monaco-diff-editor …)
```
`data-ok-status` is written by the owner (React state, HTML runtime), never in snippets.

Language and theme attributes also accept names registered in `beforeMount` (letters, digits,
`. + # - _`, up to 64 characters); React passes any string. `data-ok-options`: Monaco options as
JSON (at most 16 kB; `JSON.parse` only, prototype keys dropped; React writes it from `options`).

API mapping: see "Upstream API mapping" below.

## States
- No `data-ok-status` (no JavaScript): the textarea is the editor; loading and content hidden.
- `loading`: the loading part covers the frame (`role=status`), content invisible.
- `ready`: Monaco shown; textareas hidden (still submitted with a form: their value follows).
- `error`: Monaco couldn't load; the textareas are shown and editable (React `onChange(value,
  undefined)`, HTML `ok:code-editor:change` with `event: null`).

## Behavior
- Loading: `loader.init()` once per page; `beforeMount(monaco)` then the editor; `onMount(editor,
  monaco)`; status `ready`. Monaco is imported from the `monaco-editor` package (bundlers) or from
  `paths.vs` (`owlky-code-editor.js`: the `monaco/` folder next to it, or the script's
  `data-ok-monaco-path`).
- Models (`@monaco-editor/react`'s rules): the first model is `path ?? defaultPath` (created with
  `value ?? defaultValue` and `defaultLanguage ?? language` if it doesn't exist). A new `path`
  switches to that model (created on first use), saving the old view state and restoring the
  new one (`saveViewState`). `value` replaces the content as one undoable edit (`setValue` when
  read only) and fires no `onChange`; `language` sets the current model's language; `line`
  reveals a line; `options` → `updateOptions`. Unmount disposes the model unless
  `keepCurrentModel`.
- Diff: original and modified models from `original` / `modified` with `originalLanguage ??
  language` / `modifiedLanguage ?? language` (default `text`) and their model paths; new values
  update them (modified as an undoable edit); `line` reveals a line of the modified text (both
  sides scroll together); unmount disposes both models unless kept.
- Validation: `onValidate(markers)` / `ok:code-editor:validate` whenever the current model's
  markers change (languages with workers: JSON, CSS, HTML, TypeScript / JavaScript).
- Themes: `auto` → `owlky-light` / `owlky-dark` built from the scope's tokens (`--ok-bg-paper`,
  `--ok-text-*`, palette `-text` tones for syntax, `primary-main` cursor and focus); Monaco has one
  theme per page: the editor focused, mounted or re-themed last picks it. `data-ok-theme` and
  system scheme changes re-apply it. Default font `--ok-font-family-mono`.
- Size: `width` / `height` (default 100%; at least 300px when no height) through
  `--_ok-code-editor-width|height`; Monaco follows its container (`automaticLayout`).

## Keyboard
Monaco's keyboard map (VS Code). Tab inserts a tab: **Ctrl+M** (macOS: **Ctrl+Shift+M**) toggles
"Tab moves focus" so Tab and Shift+Tab leave the editor; **Alt+F1** (Windows / Linux) or
**Option+F1** opens Monaco's accessibility help; **F1** the command palette. Fallback textareas:
native.

## Accessibility
Monaco's input is a `textbox` (`aria-multiline`, `aria-roledescription="editor"`) named by
`ariaLabel` (React `aria-label`, HTML the textarea's `aria-label` / `aria-labelledby` /
`<label>`); `accessibilitySupport` and `tabFocusMode` stay reachable through `options`. Loading
is a polite `status`. The textareas are named. Syntax colors are AA `-text` tones on
`--ok-bg-paper`; line numbers `--ok-text-secondary`.

## Events / API
HTML `ok:code-editor:beforemount` (`{ monaco }`), `:mount` (`{ editor, monaco }`), `:change`
(`{ value, event }`), `:validate` (`{ markers }`), `:error` (`{ error }`); instance `{ status,
value, setValue(value), updateOptions(options), focus(), editor, monaco, controller }`. Diff
editor: `ok:diff-editor:beforemount | mount | error`; instance `{ status, original, modified,
setOriginal, setModified, updateOptions, editor, monaco, controller }`. Registration is opt-in:
`@owlky/html/code-editor` (exports `loader`), `owlky-code-editor.js`, or
`createCodeEditor({ beforeMount, onMount, overrideServices })` / `createDiffEditor(…)`.
React: `CodeEditor`, `DiffEditor`, `useMonaco()`, `loader`.

## Responsive
The frame is fluid (`width` 100%, never wider than its container); Monaco relayouts on resize.
The story settings sit beside the editor from 900px and above it below (the reference hides the
editor on phones; Owlky keeps both).

## Parity notes
React renders `data-ok-runtime="off"` and the status from state. Monaco's DOM (instance ids,
measured layout) is compared by the code editor e2e spec, not by the anatomy parity test.
Monaco's theme is page-wide (ADR-0034).
