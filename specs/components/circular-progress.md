# Circular progress

Reference: Minimal UI kit "Progress" page, section "Circular" (Indeterminate, Determinate, Sizes;
content only). Upstream: MUI `CircularProgress` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/progress

## Purpose
A spinner for work of unknown length (indeterminate) or an arc that shows how far a task has got
(determinate). Also the default loader of Button and IconButton (`data-ok-button-spinner`).

## Anatomy
```
span[data-ok-circular-progress][role=progressbar][aria-label|aria-labelledby]
    [data-ok-variant][data-ok-color][data-ok-size]?[data-ok-thickness]?
    [data-ok-disable-shrink]?[data-ok-track-slot]?
    [aria-valuenow][aria-valuemin][aria-valuemax]   (determinate only)
  svg[data-ok-circular-progress-svg][aria-hidden="true"][viewBox="22 22 44 44"]
    circle[data-ok-circular-progress-circle][cx=44][cy=44][r][stroke-width]
```
`r = (44 − thickness) / 2`, `stroke-width = thickness` (default 20.2 / 3.6). The track
(`enableTrackSlot`) is a `::before` ring, `size × thickness / 44` wide — no extra element.
React renders `data-ok-runtime="off"` on the root.

Upstream `sx` / `classes` don't apply. Numbers are validated (`parseNumber`): non-finite, too
long, below `min` or unit-less garbage → default. `size` accepts a number (px) or a `px` / `rem` /
`em` length. `max ≤ min` → `min + 100`; `value` is clamped to the range.

## Layout and tokens
- Size 40px default (`--ok-spacing` × 10); the reference's sizes 48 / 40 / 32 / 24 are `size`.
- Color: `--ok-c-main` of `data-ok-color` (fallback primary), `inherit` = text color; everything
  paints with `currentColor`; track ring at opacity 0.24.
- Private properties written by React (`style`) and the HTML runtime (CSSOM):
  `--_ok-progress-size`, `--_ok-progress-thickness` (only when not 3.6),
  `--_ok-progress-dasharray` / `-dashoffset` (determinate: circumference, `(1 − fraction) ×`).
- Motion: root rotates (1.4s linear); circle dash 1.4s ease-in-out (1px → 100px, offset −15 →
  −125px). Determinate: rotated −90°, offset transition `--ok-duration-standard`
  `--ok-easing-standard`. Loop timings are choreography constants, not tokens (approved).
- Reduced motion: no dash animation (fixed 80px arc), rotation 2.8s, no value transition.

## Responsive behavior
Fixed square size at every breakpoint; inline-block with `flex-shrink: 0`, so rows of indicators
wrap (story rows are wrapping flex rows). No breakpoint-specific rules.

## States
`data-ok-variant` only. Not focusable, no hover / disabled states.

## Behavior
CSS only in React. HTML runtime (`circular-progress`): on mount and whenever `data-ok-variant`,
`aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `data-ok-size` or `data-ok-thickness` change
(own MutationObserver, `attributeFilter`), writes the private properties and the circle's `r` /
`stroke-width`; `destroy` disconnects and removes them. Without the runtime: indeterminate works,
the default size works, determinate shows no arc.

## Keyboard
None (not focusable).

## Accessibility
`role="progressbar"`, named by the author (`aria-label` / `aria-labelledby`). Determinate:
`aria-valuenow` (clamped), `aria-valuemin`, `aria-valuemax`; `aria-valuetext` passes through. SVG
is `aria-hidden`. Inside a Button the loader wrapper is `aria-hidden`. Brand colors follow the
reference (ADR-0014): light colors (warning, info) are below 3:1 non-text contrast on white.

## Events / API
None. HTML: change the attributes above. React: props; `ref` = the root span.

## Parity notes
React sets the private properties through `style` (an SSR style attribute is blocked by a strict
`style-src` CSP until hydration — documented); HTML through CSSOM. Parity ignores `style`.
