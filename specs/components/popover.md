# Popover

Reference: Minimals "Popover" page, sections Click & hover, Custom arrow (content only).
Upstream: MUI `Popover` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/popover

## Purpose
Content next to an anchor, in the top layer. Runtime behavior: core `createPopoverController`
(positioning, flip, shift, Escape / outside press, focus, layer stack), shared by Menu and Tooltip.

## Anatomy
```
button[data-ok-popover-open="id"][aria-haspopup][aria-expanded][aria-controls]   (HTML trigger; or data-ok-popover-hover)
div[data-ok-popover][data-ok-paper][popover=manual][id][data-ok-placement][data-ok-arrow]?[role=dialog]?
  › span[data-ok-popover-arrow][aria-hidden]       (always rendered; shown with data-ok-arrow)
  › content
```
States written by the controller: `data-ok-open`, `data-ok-current-placement` (after a flip),
`data-ok-fallback` (no Popover API), CSSOM `--_ok-popover-x|y|arrow|duration` (no `x` / `y`
with `anchorReference="none"`).

React: `open` + `anchorEl` (element or function) + `onOpenChange(open, reason)`, `initialFocus`,
`children`. Renamed: `anchorOrigin` / `transformOrigin` → `placement` (one vocabulary for
Popover, Menu and Tooltip: side + start/center/end; the controller flips and shifts);
`onClose(event, reason)` → `onOpenChange(false, reason)` with `escape` | `backdrop`; the
Minimals arrow (`slotProps.arrow.placement`) → `arrow` (it follows the placement).
Kept (Phase 4.7): `anchorReference` (`anchorEl` · `anchorPosition` · `none`; HTML
`data-ok-anchor-reference`), `anchorPosition` (`{ top, left }`; HTML
`data-ok-anchor-position="top,left"`, written by React too), `marginThreshold`
(`data-ok-margin-threshold`), `transitionDuration` (ms, the opening animation;
`data-ok-transition-duration` → `--_ok-popover-duration` through CSSOM by the controller).
`anchorEl` also takes a virtual anchor (`{ getBoundingClientRect(), contextElement? }`, MUI
`PopoverVirtualElement`); HTML: `instance.open(virtualAnchor)`. `none` writes no coordinates:
the author's CSS positions the paper. Not applicable: `container` (top layer), `TransitionComponent`, `slots`, `slotProps`,
`sx`, `disableScrollLock` (non-modal: the page stays scrollable;
the popover follows its anchor), `disablePortal` (top layer).

## Layout and tokens
The root is a Paper (ADR-0066, 2026-11-12): `data-ok-paper` right after `data-ok-popover` (React
`popoverAttributes()` writes it; so does every popover root: Menu, Select, Autocomplete, pickers,
Walktour steps, the Editor's bubble menu and mentions, Data grid panels). `paper.css` loads first,
so `popover.css` restates the radius, translucent background and shadow; Paper adds its
`transition: box-shadow`. `elevation` (React prop, HTML `data-ok-elevation` `0`–`24`, optional)
replaces the dropdown shadow with `--ok-elevation-<n>`: the dropdown shadow rule is
`:not([data-ok-elevation])`. Paper's `variant` / `square` aren't offered on popovers (backlog).
The edge is Paper's (the style's surface edge, whole in Editorial; 0 in Soft): flat styles draw no
shadow, so the edge separates the popover from the page (ST7b). The arrow is placed from the
border box, outside the edge (it has no edge of its own).
Paper: radius `--ok-radius-md` × 1.25 (10px), padding 4px, `rgb(var(--ok-bg-paper-channel) / 0.9)`,
blur 20px, two glows (info top-right, error bottom-left, 12%), `--ok-shadow-dropdown`, max size
viewport − 32px, scrolls without an arrow. Gap 8px (12px with the arrow); 16px from the viewport
edges. Arrow 14px, `--ok-bg-paper`, 1px grey-500/12% border. Opening: fade + scale 0.96,
`--ok-duration-shorter` (none with reduced motion). Fallback: `position: fixed`, `--ok-z-dropdown`.

## Responsive behavior
Stays 16px inside the viewport at every width (shift on the cross axis, flip on the main axis,
clamp when neither side fits).

## Keyboard / Accessibility
Focus moves into the popover on open (first tabbable, else the popover) and back to the anchor on
close (`disableAutoFocus` / `disableRestoreFocus` turn this off; hover triggers do). Escape
closes the top layer only. Interactive popovers: `role="dialog"` + a name; triggers
`aria-haspopup` + `aria-expanded` (synced by the HTML runtime).

## Events / API
HTML: `ok:popover:beforeopen` (cancelable, `detail.anchor`), `ok:popover:open`,
`ok:popover:beforeclose` (cancelable, `detail.reason`: escape | backdrop | trigger | select | tab |
api), `ok:popover:close`. Instance: `{ isOpen, open(anchor), close(reason?), toggle(anchor) }`.
