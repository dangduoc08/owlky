# Autocomplete

Reference: Minimal UI kit "Autocomplete" page, sections Playground (Combo box, Controllable
states, Free solo, Multiple values, Checkboxes, Sizes) and Country select (Output label, Output
code, Variants) (content only). Upstream: MUI `Autocomplete` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/autocomplete

## Purpose
A text field with a list of suggestions (WAI-ARIA combobox + listbox popup). A composite of
TextField, Chip, IconButton and Popover; core `createComboboxController` turns keys, clicks and
blur into intent, `filterOptions` / `nextAutocompleteValue` / `moveHighlight` are shared rules.
React owns value, text, open and highlight; the HTML runtime `autocomplete` keeps them in the DOM.

## Layout and tokens
The field is a TextField; in an autocomplete its control wraps (chips row-gap 4px, chip margin
3px), the start adornment is `display: contents`, the input keeps 32px minimum, the end buttons
sit absolutely at the right (28px icon buttons, 4px padding; 64px reserved, 36px free solo),
centered on the first line (28px; small fields 20px). Clear shows on hover / focus with a value.
The toggle chevron turns when open. Paper: Popover (translucent paper, `--ok-shadow-dropdown`),
as wide as the field, min 160px; listbox max 360px, scrolls. Options: min 34px, padding 6px 8px,
4px apart, `--ok-radius-sm`, body2; selected `--ok-action-selected`, highlighted
`--ok-action-focus`, disabled 0.48. No options: 14px 16px, `--ok-text-secondary`. "+N":
secondary text.

## Behavior
Typing filters (label contains the text, case and accents ignored), opens and resets the highlight
(`autoHighlight`: first). Arrow keys open a closed list, then move the highlight (wrapping,
skipping disabled); Page keys move 5; Home / End (not free solo). Enter picks the highlighted
option or commits free text. A pick replaces the value (single, text = label) or toggles it
(multiple, text cleared); the list closes unless `disableCloseOnSelect` (multiple). Escape closes.
Backspace in an empty multiple field removes the last chip; chip delete buttons remove theirs.
The clear button empties value and text; the toggle opens / closes; a press on a closed field
opens it. Blur closes and (not free solo) puts back the chosen label (multiple: empty). An outside
press closes (Popover). `limitTags`: extra chips `hidden` while the field isn't focused, "+N".

## Keyboard
| Key | Action |
|---|---|
| ↓ / ↑ | Open, then next / previous option |
| Page Down / Page Up | ±5 options |
| Home / End | First / last option (not free solo) |
| Enter | Pick the highlighted option / commit free text |
| Escape | Close |
| Backspace (empty multiple) | Remove the last chip |

## Accessibility
`role=combobox` on the input with `aria-expanded`, `aria-controls`, `aria-activedescendant`;
listbox named by the label; options `aria-selected` / `aria-disabled`; end buttons named and out of
the tab order; chips' remove buttons named "Remove <label>"; checkbox options decorative
(`aria-hidden`, `tabindex=-1`).

## Events / API
HTML `ok:autocomplete:change` (cancelable, `{ value }`), `ok:autocomplete:open` / `close`
(`{ reason }`). Instance `{ value, setValue(value), isOpen, open(), close() }`.
React `onChange`, `onInputChange`, `onOpenChange(open, reason)`.

## Responsive
The field fills its container; the paper follows the field's width (min 160px) in the top layer.

## Parity notes
React renders `data-ok-runtime="off"` on the root and the Popover. The chip `<template>` is
HTML-only (parity skips templates); hidden chips / options / no-options are skipped by parity.
Country flags of the reference are not reproduced: options show the country code on a Label.
