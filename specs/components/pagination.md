# Pagination

Reference: Minimal "Pagination" page (sections Shapes, Variants, Sizes, Buttons, Ranges, Custom
icons, Table, Items). Upstream: MUI `Pagination` / `PaginationItem` / `usePagination` (ADR-0015).
Reference URL: https://minimals.cc/components/mui/pagination

## Purpose
Page numbers with previous / next (optional first / last) buttons and ellipses for long ranges.

## Anatomy
```
nav[data-ok-pagination][aria-label][data-ok-variant][data-ok-color][data-ok-shape][data-ok-size][data-ok-disabled]?
    HTML: [data-ok-count][data-ok-page][data-ok-sibling-count]?[data-ok-boundary-count]?[data-ok-label-page]?[data-ok-label-current]?
    React: + data-ok-runtime="off"
  ul
    li › button[type=button][data-ok-pagination-item][data-ok-type=first|previous|next|last][aria-label][disabled]? › svg[aria-hidden] (or your icon)
    li › button[type=button][data-ok-pagination-item][data-ok-type=page][value=<n>][aria-label][aria-current=page]?[disabled]? › n
    li › span[data-ok-pagination-ellipsis][aria-hidden=true] › …
```
Paging a table (HTML): `data-ok-pagination="<table id>"` + `data-ok-rows-per-page` (default 10)
without `data-ok-count`. React has no equivalent prop: the app slices its rows for `page`.

`PaginationItem` with `href` renders `a[data-ok-pagination-item]` (links; React).

Range and labels (React prop ↔ HTML attribute): `count` (default 1) ↔ `data-ok-count`; `page` /
`defaultPage` (1-based, default 1) ↔ `data-ok-page`; `siblingCount` (1) ↔ `data-ok-sibling-count`;
`boundaryCount` (1) ↔ `data-ok-boundary-count`; `showFirstButton`, `showLastButton`,
`hidePrevButton`, `hideNextButton` ↔ which buttons the markup contains;
`getItemAriaLabel(type, page, selected)` ↔ `data-ok-label-page` (default `"Go to page {page}"`) and
`data-ok-label-current` (default `"page {page}"`) for the page items the runtime builds; previous /
next / first / last keep their markup labels. `icons={{ previous, next, first, last }}` ↔ the SVG in
the markup. `renderItem(item)` + `PaginationItem` (React) for custom items or links.

Values from attributes are validated: non-integers and out-of-range values fall back to defaults.

## Layout and tokens
- Items: `--ok-spacing` × 8 (32px; `sm` 26px, `lg` 40px), padding 6px, margin 3px between items,
  body2 (`lg`: `--ok-font-size-lg`), current page weight 600; icons 20px (18 / 22).
- Shape: `circular` = `--ok-radius-full`, `rounded` = `--ok-radius-md`.
- Hover (hover-capable devices): `--ok-action-hover`. Focus-visible: 2px `--ok-text-primary` outline.
- Current page — `text`: `main` fill, `contrast` text (`standard`: `--ok-inherit-main` /
  `--ok-inherit-contrast`); `outlined`: grey 32 % borders, current `main` border and text, 8 % fill
  (`standard`: inherit main, grey 8 %); `soft`: 16 % fill, `-text` tone (`standard`: grey 16 %,
  primary text).
- Disabled: `--ok-action-disabled` text; current page `--ok-action-disabled-bg`.
- Items wrap onto more lines when the row is too narrow.

## Behavior
- React: controlled (`page` + `onChange(page)`) or uncontrolled (`defaultPage`); `onChange` fires
  with the requested page; a controlled owner refuses by not updating `page`.
- HTML runtime (`pagination`): an item click → cancelable `ok:pagination:change` `{ page }` → the
  page items and ellipses are rebuilt (DOM APIs, no HTML strings), the buttons' disabled states
  and `data-ok-page` updated; focus stays on the clicked button (or the new current page).
  Instance: `page`, `count`, `setPage(page)`, `refresh()`.
- Linked to a table (`data-ok-pagination="<table id>"`, no `data-ok-count`): `count` = row groups
  ÷ `data-ok-rows-per-page`; row groups outside the page get `hidden` (open detail rows follow
  their row); the table's `sort()` refreshes it.

## Keyboard
Native buttons: Tab / Shift+Tab move between items, Enter / Space activate.

## Accessibility
- `nav` with an `aria-label` (default "pagination navigation"); the current page has
  `aria-current="page"`; every item has a name (`getItemAriaLabel` / label templates).
- Ellipses are `aria-hidden`. Disabled items are native `disabled`.
- Brand-colored current pages (`text`, `outlined` with a color) follow the reference (ADR-0014);
  `standard` and `soft` meet AA.

## Events / API
`ok:pagination:change` (cancelable, `detail.page`).

## Responsive
Mobile first: items keep their size (≥ 24px targets) and wrap; the page never overflows.

## Parity notes
- Labels: React builds them with `getItemAriaLabel`; HTML uses the `data-ok-label-page` and
  `data-ok-label-current` templates. Defaults are identical.
- HTML only: `data-ok-pagination="<table id>"` pages a table's rows (see Behavior); in React the app
  slices its rows for `page`.
- React only: `renderItem` + `PaginationItem` (links, custom items).
