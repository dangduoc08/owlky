# Card

Reference: MUI "Card" demo page, sections Basics, Outlined Card, Complex Interaction, Media,
Primary action, UI Controls, Active state styles (content only; Minimals has no Card page — its
theme customizes MUI's Card: 16px radius, the `card` custom shadow, header padding 24/24/0 with an
`h6` title and a `body2` subheader 4px below, content padding 24). Upstream: MUI `Card`,
`CardHeader`, `CardContent`, `CardMedia`, `CardActions`, `CardActionArea` (ADR-0015). Created
with `/component`.
Reference URL: https://mui.com/material-ui/react-card/
HTML source: written by us (MUI is React only)

## Purpose
A surface for content and actions about one subject. Built on Paper (`specs/components/paper.md`,
"Composition contract"): one element carries Paper's attributes and `data-ok-card`. CSS only.

## Anatomy
```
<element>[data-ok-paper][data-ok-card][data-ok-variant][data-ok-elevation][data-ok-square]?[data-ok-raised]?
  div[data-ok-card-header]?
    div[data-ok-card-header-avatar]?                     › an Avatar
    div[data-ok-card-header-content]
      span[data-ok-typography][data-ok-variant="h6"][data-ok-card-header-title]?
      span[data-ok-typography][data-ok-variant="body2"][data-ok-color="textSecondary"][data-ok-card-header-subheader]?
    div[data-ok-card-header-action]?                     › an IconButton…
  <img|video|picture|iframe|audio>[data-ok-card-media][src]?     media element: shows the media
  <element>[data-ok-card-media]?                                 other element (default div):
    img[data-ok-card-media-image][src][alt=""]?                  a decorative cover image
  div[data-ok-card-content]?
  div[data-ok-card-actions][data-ok-disable-spacing]?
  button[type=button][data-ok-card-action-area] | a[href][data-ok-card-action-area]?   wraps media / content
```
The title and subheader are Typography roots (composition, no DOM change to Typography). The
media part may be any component's root, such as an Image (`span[data-ok-image][data-ok-card-media]`).

React (not options, HTML writes them as markup):
- `Card`: Paper's `component` (default `div`), `children`, `ref`, every attribute.
- `CardHeader`: `avatar`, `action`, `title`, `subheader` (nodes), `disableTypography`,
  `titleProps` / `subheaderProps` (Typography props, over `variant="h6" component="span"` and
  `variant="body2" color="textSecondary" component="span"`), `component` (default `div`).
- `CardContent`: `component` (default `div`).
- `CardMedia`: `component` (default `div`), `image` / `src` (alias). Media elements (`img`,
  `video`, `picture`, `iframe`, `audio`) and components (`Image`) receive `src`; any other
  element renders `img[data-ok-card-media-image][alt=""]` (MUI's background image, CSP-safe: no
  `style`). Other props pass through (`alt`, `height`, `controls`, Image's `ratio`…).
- `CardActions`: `disableSpacing`.
- `CardActionArea`: a `button type="button"`, or an `a` with `href` (`disabled` on a link removes
  `href` and sets `aria-disabled`), every button / anchor attribute.

API mapping (MUI): kept `raised`, Paper's `variant` / `elevation` / `square` / `component`,
`avatar`, `action`, `title`, `subheader`, `disableTypography`, `image`, `src`, `disableSpacing`;
`titleTypographyProps` / `subheaderTypographyProps` / `slotProps.title|subheader` → `titleProps`
/ `subheaderProps`. Not applicable: `sx`, `classes`, `slots`, other `slotProps`,
`focusVisibleClassName` and ButtonBase ripple props (CSS `:focus-visible`), MUI's title default
`body2` / `h5` by avatar (Minimals' theme: always `h6` / `body2`).

## Layout and tokens
- Root (on Paper): `position: relative`, `z-index: 0`, `overflow: hidden`, `--ok-radius-xl`
  (16px). Shadow: `--ok-shadow-card` at the default level (1, or a value Paper doesn't know);
  other levels keep Paper's `--ok-elevation-<n>` (0: none); `raised` → `--ok-elevation-8`
  (MUI's raised level); `outlined` → no shadow (Paper's outline); `square` → radius 0. Background,
  text color, outline and the shadow transition come from Paper.
- Header: flex, centered, padding `spacing × 6` (24px) top and sides, 0 bottom. Avatar slot
  `margin-inline-end: spacing × 4`; content `flex: 1 1 auto; min-width: 0`; action
  `align-self: flex-start`, margins −4px block / −8px inline end. Title block `h6`; subheader
  block `body2`, `--ok-text-secondary`, `margin-block-start: spacing` (4px).
- Media: block; media elements `width: 100%`, `img` / `picture` `object-fit: cover`; other
  elements are `position: relative; overflow: hidden` around an absolute cover image
  (`object-fit: cover`) — the author gives them a height. Media right after the header gets
  `margin-block-start: spacing × 6` (the header has no bottom padding).
- Content: padding `spacing × 6` (24px).
- Actions: flex, centered, `gap: spacing × 2` (8px, 0 with `disableSpacing`), padding 8px.
- Action area: block, full width, inherits font / color / radius, no border or padding;
  `::after` tint: `--ok-action-hover` on hover (hover-capable devices), `--ok-action-focus` +
  a 2px `--ok-text-primary` outline inset by 2px on `:focus-visible`; `:disabled` /
  `aria-disabled` → default cursor, no pointer events. Tint transition `--ok-duration-shortest`
  (none with reduced motion).
- `card.css` loads right after `paper.css` and `typography.css`.

## Responsive behavior
Fluid: the card takes its container's width (stories cap it at 345px). Nothing changes per
breakpoint; the header's content shrinks (`min-width: 0`) so long titles wrap.

## Keyboard / Accessibility
The card is not focusable. The action area is a native button or link (Tab, Enter, Space for the
button). Its content is its accessible name. Keep other actions outside the action area (nested
interactive). Cover images are decorative (`alt=""`); `img` media take the author's `alt`. Header
and content text use `--ok-text-primary` / `--ok-text-secondary` (AA in both schemes).
Selection state on an action area (MUI's "Active state styles" `data-active`) is the author's:
the stories use `aria-pressed` and story CSS.

## Events / API
None (native `click` on the action area and controls).

## Parity notes
None: React renders the same elements and attributes as the snippets (generated from the React
examples by `apps/storybook/scripts/card-snippets.mjs`). Stateful stories (Complex interaction,
Active state styles) render their first state; HTML pages toggle `hidden` / `aria-expanded` /
`aria-pressed` in a page script. Complex interaction's method section is a Collapse
(`timeout="auto"`, as MUI's `<Collapse in timeout="auto">`) around the `CardContent`: the
`collapse` runtime animates it when the page script toggles `hidden`.
