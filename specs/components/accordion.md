# Accordion

Reference: Minimal UI kit "Accordion" page — Simple, Controlled, Custom styles (content only).
Upstream: MUI Accordion (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/accordion

## Purpose
Sections that expand and collapse in place (FAQ, settings groups).

## Anatomy
```
details[data-ok-accordion][data-ok-variant][name]?[open]?   React: + data-ok-runtime="off"
  summary[data-ok-accordion-summary][aria-disabled][tabindex="-1"]?   (disabled)
    … title (your heading, e.g. <h3>) and secondary text
    span[data-ok-accordion-icon][aria-hidden="true"] › svg[data-ok-accordion-plus] | your icon
  div[data-ok-accordion-details]
  div[data-ok-accordion-actions][data-ok-disable-spacing]?
```
Native `<details>` / `<summary>`: opening, keyboard (Enter / Space on the summary) and find-in-page
work without JavaScript. Same `name` = one open at a time (exclusive group).

## Layout and tokens
- Summary: padding 16px / 8px end, `--ok-typography-subtitle1-*`; details: padding 0 16px 16px,
  `--ok-typography-body2-*`, `--ok-text-secondary`. Stories put the summary text in a Typography
  (`subtitle1`, `component="span"`, like the reference), plus a `body2` / `textSecondary` line
  in "Controlled".
- `default`: closed items are separated by `--ok-divider`; the open item is a card
  (`--ok-bg-paper`, `--ok-shadow-z8`, `--ok-radius-md`) with a 16px gutter above and below.
- `outlined`: one bordered list (`--ok-divider`, `--ok-radius-md`), items joined.
- `soft`: separate filled items (`channel(grey-500)` 8 %, 16 % when open, `--ok-radius-xl`), 8px apart; content uses `text-primary` (secondary text on the 16 % tint is below AA).
- Icon: the default plus turns into a minus; any icon rotates 180° when open.
- Actions: flex row at the end, 8px between the actions (0 with `disableSpacing`), padding 0 16px 16px.
- Disabled: `--ok-text-disabled`, no pointer events.
- Opening animates the content height where `::details-content` / `interpolate-size` are supported.

## Behavior
No runtime needed to open and close. The HTML runtime adds: `ok:accordion:beforetoggle`
(cancelable, `detail.open` = the requested state) on summary activation, `ok:accordion:toggle`
after the change, and the exclusive-group fallback where `<details name>` isn't supported
(`closeOtherDetails` in core, shared with React).

## Keyboard
`Tab` to a summary, `Enter` / `Space` toggles. Disabled summaries are skipped.

## Accessibility
The summary is the disclosure button (native `aria-expanded` semantics). Put a heading inside the
summary for the page outline. Disabled: `aria-disabled="true"`, removed from the tab order.

## Events / API
HTML: `ok:accordion:beforetoggle` (cancelable), `ok:accordion:toggle` (`detail.open`); instance
`toggle(open?)`, `isOpen`. React: `onChange(expanded)`; controlled refusal by not changing
`expanded`.

## Responsive
Full width of its container at every breakpoint; long titles wrap.

## Parity notes
Same `<details>` markup. React controls `open` from state: it prevents the summary's native toggle,
and toggles the browser makes itself (find-in-page, `<details name>`) are reported through
`onToggle` and reverted after render when refused. The HTML runtime lets the native toggle happen
and reports it (`ok:accordion:beforetoggle` / `ok:accordion:toggle`).
