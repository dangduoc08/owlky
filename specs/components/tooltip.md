# Tooltip

Reference: Minimals "Tooltip" page, sections Simple, Arrow, Variable width, Transitions,
Positioned (content only). Upstream: MUI `Tooltip` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/tooltip

## Purpose
A short text label on hover, focus or long press. Runtime behavior: core `createHoverIntent`
(timing) + `createPopoverController` (positioning; no focus move, no outside dismiss).

## Anatomy
```
trigger[aria-labelledby="id"] | trigger[aria-describedby="id"]      (describeChild)
div[data-ok-tooltip][role=tooltip][popover=manual][id][data-ok-placement][data-ok-arrow]?[data-ok-transition]?
  › span[data-ok-tooltip-arrow][aria-hidden]       (always rendered; shown with data-ok-arrow)
  › text
```

React: `title`, one element `children` (cloned: relation attribute, pointer / focus handlers,
merged ref), `describeChild`, `open` / `onOpenChange(open)`, `enterTouchDelay` (700),
`leaveTouchDelay` (1500), `disableHoverListener`, `disableFocusListener`,
`disableTouchListener`. Renamed: `TransitionComponent` (Grow / Fade / Zoom) → `transition`;
`onOpen` / `onClose` → `onOpenChange`. Kept behavior: `describeChild=false` names the trigger
(MUI sets `aria-label`; we use `aria-labelledby`, same name). Deferred: `followCursor`,
`enterNextDelay`, `disableInteractive` (always hoverable, WCAG 1.4.13). Not applicable:
`PopperProps`, `slots`, `slotProps`, `components`, `sx`.

## Layout and tokens
`--ok-palette-grey-800` (dark scheme grey-700, via `light-dark()`), white text, 11px (font-size-xs −
1px) 500 / 1.5, padding 4px 8px, radius `--ok-radius-sm`, max width 300px. Gap 8px (10px with the
arrow); arrow 10px. Transitions: grow (scale 0.75) / fade / zoom, `--ok-duration-shortest`.
`--ok-z-tooltip` in the fallback.

## Responsive behavior
Flips and shifts to stay 16px inside the viewport.

## Keyboard / Accessibility
Opens on keyboard focus (`:focus-visible` only) and closes on blur; Escape closes it (focus stays).
Hover: opens after `enterDelay` (100 ms), closes `leaveDelay` (0) + a 100 ms grace after leaving;
the tooltip is hoverable. Touch: long press. Never interactive content.

## Events / API
HTML: `ok:tooltip:open` (`detail.trigger`), `ok:tooltip:close`. Instance: `{ isOpen, show(trigger?),
hide() }`. Triggers are found by delegation (`aria-labelledby` / `aria-describedby` pointing at a
`[data-ok-tooltip]`).
