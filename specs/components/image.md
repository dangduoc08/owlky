# Image

Reference: Minimal UI kit "Image" page, sections List, Aspect ratio, Overlay (content only).
Upstream: Minimals' own `Image` (on `react-lazy-load-image-component`, ADR-0015); no upstream
link, no framework-free version. Created with `/component` (ADR-0038).
Reference URL: https://minimals.cc/components/extra/image
HTML source: written by us

## Purpose
A picture that loads lazily behind a placeholder and appears with an effect, cropped to an
aspect ratio, with an optional overlay. Native first: a plain `<img>` with `loading="lazy"`.

## Anatomy
```
span[data-ok-image][data-ok-fit][data-ok-position][data-ok-effect][data-ok-ratio]?[data-ok-overlay]?[data-ok-overlay-from]?[data-ok-disable-placeholder]?[data-ok-visible-by-default]?[data-ok-state]?
  span[data-ok-image-placeholder][aria-hidden="true"]   (› img[alt=""] preview | custom content)?
  span[data-ok-image-overlay][aria-hidden="true"]?      (with `overlay`)
  img[src][alt][loading][decoding][srcset]?[sizes]?[width]?[height]?[fetchpriority]?
  svg[data-ok-image-icon][aria-hidden="true"]?          (after an error: React renders it, the HTML runtime builds it)
```
React renders `data-ok-runtime="off"` and the placeholder span always (CSS hides it with
`disablePlaceholder` / `visibleByDefault`). `data-ok-state` is written by the owner only, never
in snippets.

## Layout and tokens
Root `display: block`, `position: relative`, `overflow: hidden`, `max-width: 100%`. The `img`
fills the root (`width` / `height` 100%, `object-fit` / `object-position` from `fit` /
`position`); with `ratio` the root takes `aspect-ratio` and the `img` is absolute. Without
`ratio` the picture keeps its own ratio (`width` / `height` attributes reserve it).
Placeholder: radial gradient, transparent white center → `grey-500 / 0.48` (the reference's SVG).
Overlay: `dark` = `grey-900 / 0.48`; a color = `linear-gradient(transparent, <main> / 0.8)`; with
`overlayFrom`: `linear-gradient(to top, <from main> / 0.24, <main> / 0.8)`. Error icon: 40% of
the box, at most 48px, `text-disabled`. Effects: `opacity` `--ok-duration-shortest`, `filter`
`--ok-duration-standard`, `--ok-easing-standard`; `blur(12px)` / `grayscale(1)` while loading.
Corners are the consumer's (stories: `--ok-radius-xl`).

## States
- No `data-ok-state` (no JavaScript, snippets): the picture shows; placeholder transparent.
- `loading`: picture `opacity: 0` (+ the effect's filter), placeholder visible.
- `loaded`: picture visible (transition), placeholder fades out.
- `error`: picture `opacity: 0` (keeps its `alt` in the accessibility tree), placeholder visible,
  icon shown.
- `visibleByDefault`: no placeholder, no effect, `loading="eager"`.
- `@media (scripting: none)`: the picture always shows (React's server markup says `loading`).
- `prefers-reduced-motion: reduce`: no transitions.

## Behavior
React: state `loading` until the `img` fires `load` / `error`; after mount (hydration) it reads
`complete` / `naturalWidth` (core `imageLoadState`) for pictures that settled before React. A new
`src` / `srcSet` starts at `loading` again. HTML runtime `image`: the same from `complete` at
setup, `load` / `error` listeners on the `img`, and a MutationObserver on `src` / `srcset` /
`sizes`. Lazy loading is the browser's (`loading="lazy"`).

## Responsive
The root is fluid (its container's width, `max-width: 100%`); a ratio keeps the shape at every
width. Stories: grids of 2 columns below 600px, 3 from 600px, 4 from 900px.

## Keyboard
Not focusable. Put it in an `a` / `button` to make it interactive (the `span` root is phrasing
content).

## Accessibility
`alt` required (React type); decorative pictures use `alt=""`. Placeholder, overlay and icon are
`aria-hidden`. A broken picture stays in the tree with its `alt`. Overlays help white text on
pictures reach AA (docs).

## Events / API
HTML: `ok:image:load` (`detail.src` = `currentSrc`), `ok:image:error` (`detail.src`); instance
`runtime.get(el, "image")` → `{ state }`. React: `onLoad(event)`, `onError(event)` (and
`imgProps.onLoad` / `onError`).

## Parity notes
HTML authors may leave the placeholder span out (no placeholder). React always renders it. Both
write `data-ok-state`; parity compares settled pictures.
