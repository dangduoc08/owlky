# Collapse

Reference: MUI "Transitions" page, section Collapse (content only; Minimals has no page).
Upstream: MUI `Collapse` (react-transition-group `Transition` props; ADR-0015, ADR-0044).
Created with `/component`.
Reference URL: https://mui.com/material-ui/transitions/
HTML source: written by us (the upstream is React only)

Scope: Collapse only. The page's Fade, Grow, Slide and Zoom are entrances and exits that the
Motion component already plays (`motion.md`: `fadeIn`, `zoomIn`, `slideInUp`…); Motion's full
version (roadmap) covers custom keyframes.

## Purpose
Shows or hides content by animating its height (or width) between a collapsed size (0 by
default) and the content's natural size. The element is closed while it carries `hidden`, so
content is shown or hidden exactly as the markup says before (or without) JavaScript. It can be
any element (React `component`, HTML an extra attribute): List nested lists, Tree view groups and
Stepper `StepContent` are Collapses.

## Anatomy
```
[data-ok-collapse][id]?[hidden]?[data-ok-orientation="horizontal"]?[data-ok-collapsed-size]?
  [data-ok-timeout]?[data-ok-timeout-exit]?[data-ok-easing]?[data-ok-easing-exit]?
  [data-ok-disable-prefers-reduced-motion]?
  › content
(HTML trigger) button | input[type=checkbox] [data-ok-collapse-toggle="<id> <id>…"]
```
`data-ok-state="entering" | "exiting"` exists only while it animates (written by the controller).

Outside the schema: `timeout="auto"` (`data-ok-timeout="auto"`) and `{ enter, exit }` (React) →
`data-ok-timeout` + `data-ok-timeout-exit`; `easing` (`data-ok-easing`, `{ enter, exit }` →
`data-ok-easing-exit`): keywords and functions only (`cubic-bezier(…)`, `steps(…)`, `linear(…)`,
`var(--ok-easing-*)`), anything else is dropped, and an easing the browser rejects falls back to
`--ok-easing-standard`. A collapsed size of 0 isn't written. React only: `component` (element
type, default `div`, props of that component pass through), `mountOnEnter`, `unmountOnExit`,
`onEnter` / `onEntering` / `onEntered` / `onExit` / `onExiting` / `onExited` (`(node) => void`),
`ref` (the element).

API mapping (MUI): kept `in`, `orientation`, `collapsedSize`, `timeout` (number, `"auto"`,
`{ enter, exit }`; `appear` is ignored), `easing`, `component`, `disablePrefersReducedMotion`,
`mountOnEnter`, `unmountOnExit`, the six callbacks (they get the element; no `isAppearing`).
Not applicable: `appear` (the first render is the markup's state), `addEndListener` (the
controller ends on the animation's `finished`), `slots` / `slotProps` / `classes` (one element,
no wrappers), `sx`, `TransitionComponent` props of react-transition-group (`nodeRef`, `enter`,
`exit`).

## Layout and tokens
- Root: `--_ok-collapse-duration: var(--ok-duration-standard)` (300ms, MUI `duration.standard`),
  `--_ok-collapse-easing: var(--ok-easing-standard)` (MUI `easeInOut`), `--_ok-collapse-reduce: 0`;
  `--_ok-collapsed-size` / `--_ok-collapse-closed-display` reset to `initial` (no inheritance).
- Closed (`[hidden]`): `display: var(--_ok-collapse-closed-display, none)`, `overflow: hidden`,
  height (horizontal: width) `var(--_ok-collapsed-size, 0)` while not animating.
- Horizontal: `display: flex; width: fit-content`, children `flex-shrink: 0` (they keep their
  width while the root's width animates).
- Animating (`[data-ok-state]`): `overflow: hidden`.
- `prefers-reduced-motion: reduce` → `--_ok-collapse-reduce: 1` (instant) unless
  `data-ok-disable-prefers-reduced-motion`.
- Padding and borders on the root stay at size 0: put them on a child.

## Behavior
Core `createCollapseController(element, options)` (React layout effect, HTML runtime
`collapse`) watches `hidden` with a MutationObserver (runs before the next paint):
- **Enter** (`hidden` removed): `onEnter`, `data-ok-state="entering"`, measure the natural size,
  animate (Web Animations API) from the collapsed size (or the current size when interrupted) to
  it, `onEntering`; when it finishes, drop the state, `onEntered`. At rest the size is `auto`.
- **Exit** (`hidden` added): `onExit`, `data-ok-state="exiting"`; if author CSS hides it already
  (`display: none`), an inline `display: … !important` (the value it had while open, CSSOM; important
  because Tailwind's preflight hides `[hidden]` with `!important`) keeps it rendered;
  animate from the current size to the collapsed size, `onExiting`; when it finishes, drop the
  state and the inline display, `onExited`.
- Duration: `timeout` (ms), `"auto"` (Material's formula on the distance, ≤ 3s) or the
  stylesheet's `--_ok-collapse-duration`. Duration 0, reduced motion or no `element.animate`:
  instant, the six callbacks still run in order.
- An interruption cancels the running animation and starts from its current size.
- React `unmountOnExit`: children removed after `onExited`, rendered again when `in`; with
  `mountOnEnter` alone they stay after the first opening.
- HTML runtime: reads the options (re-read on attribute changes), writes `collapseStyle` through
  CSSOM. Triggers: `[data-ok-collapse-toggle="<ids>"]` on a checkbox (`change`: open while
  checked) or a button (`click`: toggles every named collapse to the opposite of the first one's
  state, writes `aria-expanded`). Ids are space-separated; unknown ids and `data-ok-runtime="off"`
  elements are skipped.

## Responsive behavior
No breakpoints: the root takes its container's width (vertical) or its content's (horizontal).
The story's rows are capped at 250px and shrink on phones; nothing overflows at 375px.

## Keyboard
None: the trigger (button, switch) handles keys.

## Accessibility
- Closed = `hidden`: out of the accessibility tree and the tab order. With a collapsed size the
  visible slice stays in both (as MUI): don't put controls there.
- Buttons that open a collapse carry `aria-expanded` + `aria-controls` (the HTML button trigger
  writes `aria-expanded`).
- Reduced motion honored by default.

## Events / API
HTML: `ok:collapse:enter`, `entering`, `entered`, `exit`, `exiting`, `exited` (bubbling,
`detail: { in }`). Instance: `{ in, status, show(), hide(), toggle(force?) }`. React: the six
callbacks.

## Parity notes
React adds `data-ok-runtime="off"` (and `style` for a collapsed size, ignored by parity). The story
snippet adds the HTML-only trigger `data-ok-collapse-toggle` on the switch input (ignored by
parity).
