# Drawer

Reference: Minimal UI kit "Drawer" page, section "Anchor" (content only). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/drawer

## Purpose
A modal panel that slides in from an edge of the screen (navigation, filters, details).

## Anatomy
```
[trigger] button[data-ok-button][aria-haspopup="dialog"]     HTML: [data-ok-drawer-open="<id>"]
dialog[data-ok-drawer][data-ok-anchor][aria-label | aria-labelledby]   React: + data-ok-runtime="off"
  div[data-ok-drawer-content]                                the paper; any content
    … HTML close: [data-ok-drawer-close] (inside) or [data-ok-drawer-close="<id>"]
```
Scrolling content: put it in a Scrollbar inside the content — `[data-ok-drawer-content] ›
section[data-ok-scrollbar]`; the Scrollbar fills the panel and scrolls (the panel stops scrolling).
The dialog then focuses the Scrollbar first on open (it is the first focusable element).
The `<dialog>` is a transparent full-viewport container; the content is the paper. A click whose
target is the `<dialog>` itself is a backdrop click.

## Options

| `disableEscapeKeyDown` | `data-ok-disable-escape-key-down` | flag | boolean | off | Temporary only: Escape doesn't request close. |
| `open` | `open | hidden` · event `ok:drawer:close` | state | — | — | Open state (`open` / `defaultOpen`; HTML initial: `data-ok-open`). |
<!-- /options:drawer -->

React: `<Drawer variant open | defaultOpen onOpenChange(open, reason)>` holds the state (reason:
`"escape"` · `"backdrop"` · `"close"`; refuse by not changing `open`); `anchor`, `hideBackdrop` and
`disableEscapeKeyDown` are props of `DrawerContent`. HTML initial state: `data-ok-open` (temporary)
or no `hidden` attribute (persistent); refuse a close with `ok:drawer:beforeclose`.

Docked variants (`persistent`, `permanent`) render `<aside>` in the page flow — no backdrop, no focus
trap, no scroll lock; their trigger toggles and carries `aria-expanded` + `aria-controls`. Put the
drawer and the page area in a flex row (left / right) or column (top / bottom).

## Layout and tokens
- Paper `--ok-bg-paper`, text `--ok-text-primary`; backdrop: native `::backdrop` with `--ok-backdrop` (shared with the Backdrop component, which can't
  sit in the top layer; `hideBackdrop` matches its `invisible`); stacking `--ok-z-modal`
  (fallback path).
- `left` / `right`: full height, width from the content, at most `100% - 56px`; shadow
  `--ok-shadow-dialog-start` (left) / `--ok-shadow-dialog` (right).
- `top` / `bottom`: full width, height from the content, at most `100% - 56px`; shadow
  `--ok-shadow-z16`. Taller content scrolls inside the Scrollbar placed in the paper (without one,
  the paper itself scrolls).
- Opening slides the paper in from its edge and fades the backdrop (`--ok-duration-short`,
  `--ok-easing-decelerate`) where `@starting-style` is supported; closing is immediate.
  `prefers-reduced-motion` disables both.

## Behavior (`core` `createModalController`)
- **Open:** `showModal()` (fallback: `open` + `data-ok-fallback`, siblings inert, ADR-0006); push onto
  the layer stack; lock page scroll; focus `[autofocus]` → first tabbable → content.
- **Dismiss requests** (Escape, backdrop) are reported, not acted on: React updates state (controlled
  drawers may refuse); HTML emits cancelable `beforeclose`. Only the topmost layer reacts.
- **Close:** release lock and stack; focus returns to the trigger if focus was lost.
- **External close** (`<form method="dialog">`): state syncs. **Removal / unmount while open:**
  cleanup without focus restoration.

## Keyboard
`Tab` / `Shift+Tab` stay inside the drawer (native modals may hand focus to browser UI); `Escape`
requests close.

## Accessibility
Role `dialog`, modal. A name is required (`aria-label` or `aria-labelledby`). Background inert.
Focus returns to the trigger. Triggers carry `aria-haspopup="dialog"`.

## Events / API
HTML: `ok:drawer:beforeopen` (cancelable) · `ok:drawer:open` · `ok:drawer:beforeclose`
(cancelable, `detail.reason`) · `ok:drawer:close` (`reason`: `escape` `backdrop` `trigger` `api`
`native`). Instance (`runtime.get(el, "drawer")`): `open(trigger?)`, `close(reason?)`, `toggle()`,
`isOpen`. React: `<Drawer open defaultOpen onOpenChange>`, `DrawerTrigger`, `DrawerContent`,
`DrawerClose`.

## Responsive
Same anchors at every breakpoint. The `56px` gap keeps the backdrop reachable on small screens.
