# Markdown

Reference: Minimal UI kit "Markdown" page (one demo: "Html content" and "Markdown content" side by
side), content only. Upstream: react-markdown 10 (ADR-0015), on unified / remark / rehype
(ADR-0035). Created with `/component`.
Reference URL: https://minimals.cc/components/extra/markdown
HTML source: built from unified (remark / rehype)

## Purpose
Render Markdown (GitHub Flavored by default) as styled content, safely: no HTML strings, unsafe
URLs removed, raw HTML shown as text unless `rawHtml` (then sanitized by an allow list). One
pipeline in core (`@owlky/core/markdown`): remark-parse + remark-gfm → remark plugins →
remark-rehype → (rehype-raw → sanitizer) → rehype plugins → Owlky's last step (react-markdown's:
raw HTML as text or dropped, element filters, URL transform, cell alignment, external links,
highlighting, task labels). React maps the tree to elements; the HTML runtime builds DOM with
`createElement` / `setAttribute` / CSSOM.

## Anatomy
```
div[data-ok-markdown][data-ok-images]?[data-ok-images-ratio]?[data-ok-gfm="false"]?[data-ok-raw-html]?[data-ok-skip-html]?[data-ok-unwrap-disallowed]?[data-ok-external-links]?[data-ok-allowed-elements]?[data-ok-disallowed-elements]?
  …rendered content: h1–h6, p, a, strong, em, del, code, ul / ol › li, blockquote, hr, img (or
    span[data-ok-image] › span[data-ok-image-placeholder] + img with `images="image"`), br,
    table › thead / tbody › tr › th / td (style text-align from the column alignment),
    pre › code[class="hljs language-x"] › span.hljs-* (with a highlighter),
    li.task-list-item › label › input[type=checkbox][disabled][checked]? + text,
    section[data-footnotes].footnotes › h2.sr-only + ol › li[id] (GFM footnotes)
  pre[data-ok-markdown-source][hidden]      (HTML only: the Markdown text, escaped; last child)
```
Elements never rendered, whatever the options and plugins: `script style iframe frame frameset
object embed applet base link meta template noscript`. Attributes never written: `on*`, invalid
names, `srcdoc`, `is`; `style` only through CSSOM.

## Layout and tokens
Root: body1, `text-primary`, `overflow-wrap: break-word`; first child no top margin, last
rendered child no bottom margin. Headings: typography h1–h6 tokens, margins 40px (h1, h2) / 24px
top, 8px bottom. Paragraphs 0 0 20px. Links `primary-main` (brand, ADR-0014), no underline,
underline on hover, focus, and inside quotes and footnotes (secondary text: link-in-text-block).
Lists: padding-left 16px, margin-bottom 12px, items line-height 2. Task boxes 16px, radius xs,
`grey-500 / 0.24`, checked `primary-main` with a check of two gradient strokes in
`primary-contrast-text` (no image: CSP). Blockquote: padding 24 24 24 64px, 8px left border
`grey-500 / 0.08`, `text-secondary`, 24px / 1.5, a 72px “ in `text-disabled`. Hr: 32px margins,
`divider`. Images: max-width 100%, radius xl (as Image: the Image's root has the radius). Inline code: `grey-500 / 0.2`, text primary, mono
0.875em, radius xs. Code blocks: `grey-900`, white mono body2 / 1.5, padding 24px, radius md,
lines wrap; syntax colors as the Editor (palette `*-light`, ≥ 4.5:1 on grey-900). Tables: width
100%, body2, 1px `divider` borders, cells 8px, header bold, odd body rows `bg-neutral`.
Footnotes: top rule, body2 `text-secondary`; `.sr-only` visually hidden. Source `pre`: mono body2,
pre-wrap.

## Behavior
- Raw HTML (`html` nodes): default text (escaped, react-markdown); `skipHtml` drops it (wins over
  `rawHtml`); `rawHtml` parses it (rehype-raw), then `sanitizeSchema` (GitHub's + `u`, `mark`,
  `style` limited to `text-align` / `text-transform`); ids get `user-content-` (clobbering) and
  `#id` links to prefixed ids follow.
- URLs (`href` on any element, `xlink:href`, and html-url-attributes' list: `src`, `cite`,
  `action`, `formAction`, `poster`…) go through `urlTransform`; `srcset` with an unsafe candidate
  is dropped. Default: relative or `http`, `https`, `mailto`, `irc`, `ircs`, `xmpp`.
- `externalLinks`: absolute `http(s)` links get `target="_blank"`; every `target="_blank"` link
  gets `rel` `noopener noreferrer`.
- Table cell `align` → `style="text-align: …"` (react-markdown's default); whitespace text in
  table parts is dropped (React and the DOM agree).
- Highlighting: `pre > code` holding only text, with a `language-` / `lang-` class the
  highlighter knows (not `no-highlight`): children replaced by the highlighter's tree, `hljs`
  class added; a throwing grammar leaves the text.
- Task list boxes (and raw-HTML `input[type=checkbox]` first in a `li` / `p`) are wrapped with the
  phrasing content after them in a `label` (axe `label`; after the filters, so they can't drop it).
- HTML runtime: reads the source `pre`'s text, renders before it, hides it; re-renders when the
  text or an option attribute changes; no source → leaves the markup alone (server-rendered).
  Errors (both element lists) → `ok:markdown:error`, source shown again. `async: true` uses
  `markdownTreeAsync` and writes only the latest result (nothing after destroy).
- React `Markdown` is synchronous and hook-free (server components); `MarkdownHooks` processes
  in an effect.

## Keyboard
None of its own: links are native tab stops; checkboxes are disabled.

## Accessibility
Headings keep their levels (shift them with `components` or plugins). Images keep their `alt`.
Task boxes are disabled checkboxes named by their label. Code blocks wrap (no scroll region, 320px
reflow). Footnote label `h2.sr-only` is read but hidden. Brand-colored links exempt from
`color-contrast` (ADR-0014), underlined where the surrounding text is secondary.

## Events / API
HTML `ok:markdown:render` (`{ value }`), `ok:markdown:error` (`{ error }`). Instance
`{ value, setValue(markdown), render() }`. Registration is opt-in: `@owlky/html/markdown`,
`owlky-markdown.js`, or `createMarkdown({ … })`. React `MarkdownHooks` `onError(error)`.

## Responsive
Content flows at every width: images and tables are 100% wide at most, cells and code wrap
(`overflow-wrap`), headings use the responsive typography tokens. The story puts its card full
width; no breakpoint of its own.

## Parity notes
React renders `data-ok-runtime="off"` on the root; HTML keeps the hidden source `pre` (parity
skips `[hidden]`). Both renderers write the same attributes (`markdownElementAttributes`) and the
same inline styles through CSSOM (parity ignores `style`). React writes `checked` / `value` of
inputs as `defaultChecked` / `defaultValue` (the attributes match).
