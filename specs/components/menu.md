# Menu

Reference: Minimals "Menu" page, sections Simple, Selected, Max height (content only).
Upstream: MUI `Menu`, `MenuItem`, `MenuList` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/menu

## Purpose
Choices on a temporary surface: a Popover holding a WAI-ARIA menu. Keyboard logic: core
`menuKeyTarget` / `initialMenuItem` / `createTypeahead`.

## Anatomy
```
button[data-ok-popover-open="id"][aria-haspopup=menu][aria-expanded]
div[data-ok-popover][popover=manual][id][data-ok-placement=bottom-start]
  › span[data-ok-popover-arrow]
  › ul[data-ok-menu][role=menu][aria-labelledby][data-ok-dense]?
      › li[data-ok-menu-item][role=menuitem][tabindex=-1][data-ok-selected]?[aria-disabled]?…
```

React: `Menu` `open` / `anchorEl` / `onOpenChange(open, reason)` (escape | backdrop | select |
tab), `placement` (default `bottom-start`), `paperProps`; `MenuItem` `onClick` (choosing closes
the menu unless `preventDefault()`). Renamed: `onClose` → `onOpenChange`; `MenuListProps` →
props on `Menu` (they go to the list); `PaperProps` / `slotProps.paper` → `paperProps`.
Kept: `variant="selectedMenu"` behavior (focus the selected item) as the only behavior; MUI
`autoFocusItem` always on. Deferred: `variant="menu"`, nested menus. Not applicable:
`TransitionComponent`, `sx`, `classes`, `component`.

## Layout and tokens
Items: padding 6px 8px, radius `--ok-radius-sm`, body2, 4px between items, min height 34px;
hover `--ok-action-hover`, focus `--ok-action-focus` (+ 2px inner outline on focus-visible),
selected `--ok-action-hover` + semibold, disabled opacity 0.48; dense 4px block; divider 1px.
Paper: see popover.md (scrolls when its max height is set).

## Responsive behavior
The paper stays 16px inside the viewport; long menus scroll inside it.

## Keyboard / Accessibility
Opening focuses the selected (or first) enabled item. ArrowDown / ArrowUp (wrap), Home, End,
typeahead (500 ms buffer; a repeated letter cycles), Enter / Space choose, Escape closes (focus
returns to the trigger), Tab closes. Disabled items are skipped.

## Events / API
HTML: `ok:menu:select` (cancelable, `detail.item`) on the list, then the popover closes (reason
`select`). Instance: `{ select(item) }`. Popover events and instance as in popover.md.
