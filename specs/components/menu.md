# Menu

Reference: Minimals "Menu" page, sections Simple, Selected, Max height (content only).
Upstream: MUI `Menu`, `MenuItem`, `MenuList` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/menu

## Purpose
Choices on a temporary surface: a Popover holding a WAI-ARIA menu. Keyboard logic: core
`menuKeyTarget` / `initialMenuItem` / `createTypeahead`.

## Anatomy
```
button[data-ok-popover-open="id"][aria-haspopup=menu][aria-expanded]
div[data-ok-popover][data-ok-paper][popover=manual][id][data-ok-placement=bottom-start]
  › span[data-ok-popover-arrow]
  › ul[data-ok-menu][role=menu][aria-labelledby][data-ok-dense]?
      › li[data-ok-menu-item][role=menuitem][tabindex=-1][data-ok-selected]?[aria-disabled]?…
      › li[data-ok-menu-submenu][role=none]                         (a submenu, Phase 4.5)
          › div[data-ok-menu-item][role=menuitem][tabindex=-1][id][aria-haspopup=menu][aria-expanded][aria-controls]
              › label › svg[data-ok-menu-submenu-icon][aria-hidden]   (chevron, mirrored with dir=rtl)
          › div[data-ok-popover][data-ok-paper][popover=manual][id][data-ok-placement=right-start]   (left-start right to left)
              › span[data-ok-popover-arrow] › ul[data-ok-menu][role=menu][aria-labelledby=trigger id] › …
ul[data-ok-menu][role=menu][aria-label]                              (standalone MenuList, no popover)
  › li[data-ok-menu-item][tabindex=0]   (the focus item: selected, else first; `variant="menu"`: first)
```
The submenu's popover is a DOM descendant of the menu's popover (so presses inside it aren't
"outside"), in the top layer. Fallback path (no Popover API): the submenu is `position: fixed`
inside the paper, whose `backdrop-filter` makes it the containing block (positions may be off;
documented limitation of old browsers).

React: `Menu` `open` / `anchorEl` / `onOpenChange(open, reason)` (escape | backdrop | select |
tab), `placement` (default `bottom-start`), `paperProps`; `MenuItem` `onClick` (choosing closes
the menu unless `preventDefault()`). Renamed: `onClose` → `onOpenChange`; `MenuListProps` →
props on `Menu` (they go to the list); `PaperProps` / `slotProps.paper` → `paperProps`.
Kept: `variant` (`selectedMenu` default · `menu`: always the first item), `disableAutoFocusItem`
(focus the list; React renders `tabindex="-1"`, HTML writes it), `disabledItemsFocusable`,
`disableListWrap` (attributes on the list, read by core `menuItems` / `initialMenuItem` /
`menuKeyTarget`), `anchorReference` / `anchorPosition` / `marginThreshold` /
`transitionDuration` (passed to the Popover, see popover.md). React `MenuList` works alone
(`autoFocus` focuses the list and gives it `tabindex="0"`, `autoFocusItem` focuses the focus
item; both on mount; HTML: the native `autofocus` attribute), the focus item takes the tab stop
(`tabindex="0"`, MUI's active item). Nested menus (no MUI API; Base UI / WAI-ARIA submenus):
React `MenuSubmenu` (`label`, `disabled`, `id`, `triggerProps`, `paperProps`, list props),
HTML the anatomy above. Not applicable:
`TransitionComponent`, `sx`, `classes`, `component`.

## Layout and tokens
Items: padding 6px 8px, radius `--ok-radius-sm`, body2, 4px between items, min height 34px;
hover `--ok-action-hover`, focus `--ok-action-focus` (+ 2px inner outline on focus-visible),
selected `--ok-action-hover` + semibold, disabled opacity 0.48; dense 4px block; divider 1px.
Paper: see popover.md (scrolls when its max height is set).

## Responsive behavior
The paper stays 16px inside the viewport; long menus scroll inside it.

## Keyboard / Accessibility
Opening focuses the selected (or first) enabled item. ArrowDown / ArrowUp (wrap), Home, End,
typeahead (500 ms buffer; a repeated letter cycles; `aria-hidden` parts of an item are left out), Enter / Space choose, Escape closes (focus
returns to the trigger), Tab closes. Disabled items are skipped.

Submenus (core `submenuKeyAction`, `createSubmenuHover`): ArrowRight, Enter, Space or a click on
a trigger open its submenu and focus its focus item; ArrowLeft inside closes it and focuses the
trigger; Escape closes the top submenu only (focus back to its trigger). Right to left (computed
`direction`), ArrowLeft opens and ArrowRight closes, and the submenu opens on the left. Moving
to another item of a menu closes the submenus open there. Mouse: resting 100 ms on a trigger
opens its submenu without moving focus; resting on another item of the same menu closes it;
crossing items on the way into a submenu cancels. Choosing an item anywhere, Tab and a press
outside close the whole menu; closing the menu closes its submenus.

## Events / API
HTML: `ok:menu:select` (cancelable, `detail.item`) on the list, then the popover closes (reason
`select`). Instance: `{ select(item) }`. Popover events and instance as in popover.md.
