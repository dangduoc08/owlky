# List

Reference: Minimals "List" page, sections Simple, Nested, Folder, Selected, Controls, Switch
(content only). Upstream: MUI `List`, `ListItem`, `ListItemButton`, `ListItemIcon`,
`ListItemAvatar`, `ListItemText`, `ListSubheader` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/list

## Purpose
Rows of text, icons, avatars and controls. CSS only, plus a small HTML runtime that opens and
closes nested lists.

## Anatomy
```
ul[data-ok-list][data-ok-dense]?[data-ok-disable-padding]?
  › li[data-ok-list-subheader][data-ok-color][…]?                     (first; sticky)
  › li[data-ok-list-item][data-ok-align-items]?[data-ok-dense]?[data-ok-disable-gutters]?
      [data-ok-disable-padding]?[data-ok-show-divider]?
      › (button[type=button] | a)[data-ok-list-item-button][data-ok-selected]?[…]?
          › span[data-ok-list-item-icon] | span[data-ok-list-item-avatar]
          › span[data-ok-list-item-text][data-ok-inset]?
              › span[data-ok-list-item-text-primary] + span[data-ok-list-item-text-secondary]?
          › span[data-ok-list-item-expand-icon][aria-hidden=true]?    (button with aria-expanded)
      › span[data-ok-list-item-secondary-action]?                     (end action)
      › ul[data-ok-list][id][hidden]?                                 (nested list)
```
A divider between rows sits in a plain `li` (a `ul` may only hold `li`); between lists it sits
outside them. Controls (checkbox, switch) are never inside a `ListItemButton`: a checkbox at the
start is labelled by a `<label for>` in the text, a switch at the end by `aria-labelledby`.

`disabled` → no `href` + `aria-disabled`), `ListItemText primary` / `secondary` /
`disableTypography` (children = primary), `ListItemExpandIcon` (beyond upstream: the chevron

`secondaryAction`), `ListItem button` (removed upstream). Dense propagates through CSS (descendant
selector), not context.

## Layout and tokens
List padding 8px block (0 with `disablePadding` or a subheader first). Item / button padding
8px 16px (`dense` 4px block, `disableGutters` 0 inline); 40px rows with a 24px icon, 38px with
text only. Icon / avatar `margin-inline-end` 16px, `flex-start` → `margin-top` 8px. Primary text
subtitle2 (14px 600 / 22px), secondary body2 `--ok-text-secondary` (grey-700 on a selected row in
the light scheme: AA on the tint). Subheader 48px line, 14px 500, `--ok-text-secondary` on
`--ok-bg-paper`, `inset` 56px. Secondary action 16px from the end, the item (or its button)
keeps 48px for it. Nested rows start 32px in. Hover `--ok-action-hover`; selected primary
channel / 0.08 (hover 0.16, focus 0.2); focus-visible 2px `--ok-text-primary` outline inside the
row + `--ok-action-focus`; disabled opacity 0.48.

## Responsive behavior
Fluid: rows take the container's width; text wraps inside `ListItemText` (`min-width: 0`).

## Keyboard / Accessibility
Native buttons and links. A button with `aria-expanded` + `aria-controls` opens / closes the
nested list (Enter / Space). `selected` is visual only: add `aria-current`. Brand-colored
`primary` subheader is exempt from `color-contrast` (ADR-0014).

## Events / API
HTML: `ok:list:toggle` (cancelable, `detail: { open, list }`) on the button's list, then
`aria-expanded` and the nested list's `hidden` flip. `runtime.get(list, "list").toggle(button,
open?)`. React: app state (`aria-expanded`, `hidden`).
