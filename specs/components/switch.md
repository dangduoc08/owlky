# Switch

Reference: Minimal UI kit "Switch" page, sections Basic, Sizes, Placements, Colors (content only);
MUI demo section Customization (thumb icons).
Upstream: MUI `Switch` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/switch

## Purpose
Turn one setting on or off, with immediate effect. A native checkbox with `role="switch"`; CSS
only. Labels come from `FormControlLabel`. Used by Table's "Dense" toggle.

## Anatomy
```
span[data-ok-switch][data-ok-color][data-ok-size][data-ok-edge]?
  input[type=checkbox][role=switch][data-ok-switch-input]   (covers the target, opacity 0)
  span[data-ok-switch-track][aria-hidden="true"]
  span[data-ok-switch-thumb][aria-hidden="true"]
    span[data-ok-switch-icon]?            (icon: shown while off, and while on without a checked icon)
    span[data-ok-switch-checked-icon]?    (checkedIcon: shown while on)
```
React `ref` and the remaining props go to the **input**; `className` / `style` to the root.

React only: `onChange(checked)`. `icon` / `checkedIcon` (React nodes) render the thumb's
icon parts; HTML writes the same parts in the thumb. CSS picks the one for the state (`:has(> input:checked)`):
icons are centered in the thumb at 80% of its size, `--ok-text-secondary`, the checked icon in the
track color (`--_ok-main`). Upstream `disableRipple`, `sx`, `classes`, `slots`, `slotProps` don't apply.

## Layout and tokens
- Medium: track 34 × 20px (`--ok-spacing` × 8.5 × 5), thumb 14px (× 3.5), inset 3px (× 0.75),
  root padding 9px 12px → 58 × 38px. Small: track 26 × 16px, thumb 10px, padding 4px 7px → 40 × 24px.
- Track off: `rgb(--ok-palette-grey-500-channel / 0.48)`; on: `--ok-c-main` (`default` =
  `--ok-text-primary`; its thumb is `grey-800` in dark schemes via `light-dark()`).
- Thumb white, `--ok-shadow-z1`; moves `track − thumb − 2 × inset` (14px / 10px);
  `--ok-duration-shortest` `--ok-easing-standard`.
- Hover: a 9px halo (main channel at 0.08, off: `--ok-action-hover`). Focus-visible: 2px
  `--ok-text-primary` ring around the track, offset 2px. Disabled: track opacity 0.48.
- `edge`: −8px margin on that side.

## Responsive behavior
Fixed size at every breakpoint; targets ≥ 24px high. Rows wrap.

## States
From the input via `:has()`: `:checked`, `:disabled`, `:focus-visible`, plus `:hover`.

## Behavior
Native toggling; no runtime.

## Accessibility
`role="switch"` (announced on / off). Name from the label, `aria-label` or `aria-labelledby`.
Off track ≈ 1.6:1 on white: follows the reference (approved); the white thumb with its shadow
carries the shape. Brand colors follow the reference (ADR-0014).

## Events / API
HTML: native `change`. React: `onChange(checked)`, `checked` / `defaultChecked`.
