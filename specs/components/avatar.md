# Avatar

Reference: Minimal UI kit "Avatar" page, sections Image, Icon, Letter, Variant, Grouped, With badge,
Sizes (content only). Upstream: MUI `Avatar`, `AvatarGroup` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/avatar

## Purpose
A person or an entity: a picture, initials or an icon. AvatarGroup overlaps several with a "+N".

## Anatomy
```
span[data-ok-avatar][data-ok-variant][data-ok-color][data-ok-size]?[data-ok-avatar-surplus]?
  img[src][alt] | text | svg[aria-hidden] | span[data-ok-avatar-fallback][aria-hidden] (HTML, after an image error)
div[data-ok-avatar-group][data-ok-spacing] › span[data-ok-avatar]… › span[data-ok-avatar][data-ok-avatar-surplus]?
```
React renders `data-ok-runtime="off"` on avatars.

## Layout and tokens
40px default (`--ok-spacing` × 10), `size` → `--_ok-avatar-size`; letters 0.45 × size,
semibold; `rounded` `--ok-radius-lg`, `square` 0. Default background `--ok-palette-grey-300`
with `--ok-palette-grey-700` letters (AA; the reference uses `text-secondary`); colors
`--ok-c-main` / `--ok-c-contrast`. Group: 2px `--ok-bg-paper` border, overlap −8px (small −16px);
surplus `primary-lighter` / `primary-dark`, 0.32 × size.

## Behavior
React: on image error, children → first letter of `alt` → a person icon. HTML runtime `avatar`:
`data-ok-size` → `--_ok-avatar-size` (CSSOM, observed); `error` on an `img` (capture) → the image
gets `hidden` and, if the avatar has no other content, a `span[data-ok-avatar-fallback]` with the
alt's first letter (textContent).

## Keyboard / Accessibility
Not focusable. Image avatars are named by `alt`; letters / icons are decorative unless the author
adds `role="img"` + `aria-label`. Colored backgrounds follow the reference (ADR-0014).

## Events / API
None.

## Parity notes
HTML writes the surplus avatar; React computes it from `max` / `total`.
