# Avatar

Reference: Minimal UI kit "Avatar" page, sections Image, Icon, Letter, Variant, Grouped, With badge,
Sizes (content only). Upstream: MUI `Avatar`, `AvatarGroup` (ADR-0015). Created with `/component`.
Reference URL: https://minimals.cc/components/mui/avatar
Color preview: Minimal UI kit "Utilities" page, section Color pickers › Preview
(https://minimals.cc/components/extra/utilities, roadmap 4.23; upstream: the kit's own
`ColorPreview`).

## Purpose
A person or an entity: a picture, initials or an icon. AvatarGroup overlaps several with a "+N".

## Anatomy
```
span[data-ok-avatar][data-ok-variant][data-ok-color][data-ok-size]?[data-ok-avatar-surplus]?
  img[src][alt] | text | svg[aria-hidden] | span[data-ok-avatar-fallback][aria-hidden] (HTML, after an image error)
div[data-ok-avatar-group][data-ok-spacing] › span[data-ok-avatar]… › span[data-ok-avatar][data-ok-avatar-surplus]?
```
Color preview: an AvatarGroup of color dots. `span[data-ok-avatar][data-ok-swatch=<css color>]`
(empty: no person icon) and the group's surplus as plain text ("+13"); name the group
(`role="img"` + `aria-label` listing the colors). React renders `data-ok-runtime="off"` on avatars.

`swatch` (React; HTML `data-ok-swatch`): the avatar's background, a CSS color or `var(--ok-…)`

`--_ok-swatch` (React `style`, HTML `avatar` runtime through CSSOM).

AvatarGroup `max` (5, at least 2), `total`, `renderSurplus(n)`, `variant` (cloned onto the
children). Beyond MUI, from the reference: `color` (Minimals), `size` (the reference sizes with
`sx`). AvatarGroup `spacing`: `medium`, `small` or a number of px (MUI). Not applicable: `sx`,
`classes`, `slots`, `slotProps`, `component`.

## Layout and tokens
40px default (`--ok-spacing` × 10), `size` → `--_ok-avatar-size`; letters 0.45 × size,
semibold; `rounded` `--ok-radius-lg`, `square` 0. Default background `--ok-palette-grey-300`
with `--ok-palette-grey-700` letters (AA; the reference uses `text-secondary`); colors
`--ok-c-main` / `--ok-c-contrast`. Group: 2px `--ok-bg-paper` border, overlap −8px (small −16px;
a number n → −n px through `--_ok-overlap`, core `avatarGroupStyle`);
surplus `primary-lighter` / `primary-dark`, 0.32 × size. Swatch avatars: background
`--_ok-swatch` (grey 500 until set) with a 1px inset ring (`--ok-palette-grey-500-channel` at
0.16); in a group that holds swatches the surplus is text: no circle, `--ok-text-primary`,
`--ok-typography-subtitle2-*`, 2px after the last dot (the kit's ColorPreview: 16px dots
overlapping by 6px, `spacing={6}`).

## Behavior
React: on image error, children → first letter of `alt` → a person icon. HTML runtime `avatar`:
`data-ok-size` → `--_ok-avatar-size` and `data-ok-swatch` → `--_ok-swatch` (CSSOM, observed); `error` on an `img` (capture) → the image
gets `hidden` and, if the avatar has no other content, a `span[data-ok-avatar-fallback]` with the
alt's first letter (textContent). HTML runtime `avatar-group` (behavior-only folder): a numeric
`data-ok-spacing` → `--_ok-overlap` (CSSOM, observed); React writes the same property in `style`.

## Keyboard / Accessibility
Not focusable. Image avatars are named by `alt`; letters / icons are decorative unless the author
adds `role="img"` + `aria-label`. Colored backgrounds follow the reference (ADR-0014).

## Events / API
None.
