## Purpose
Choose one or more values from a list. The field shows the value; the list opens in a Popover
(Menu's paper and items) under it. `native` uses the browser's `<select>` instead.

## Layout and tokens
The field box mirrors TextField (text-field.md): outlined 1px `grey-500` at 0.2 → hover
`text-primary` → focus 2px accent; filled tint `grey-500` 0.08 (hover / focus 0.16, disabled
0.24) with a 2px inset focus ring; standard underline growing from the middle; radius
`--ok-radius-md`; text 15 / 24px; padding 16 / 14px (small 8 / 14px), filled 24 12 8 (small
20 12 4; no label 16 12 / 8 12), standard 4px 0 (small 2px 0); 32px (standard 24px) at the end
for the arrow (20px, `text-secondary`, turns 180° while open). InputLabel: TextField's label
positions per variant and size, floated with focus (`:focus-within` on the FormControl), a value
(the hidden input `:not(:placeholder-shown)`), a native select or `shrink`; colors: focus
`--_ok-form-focus-own`, error `--ok-palette-error-text`, disabled `--ok-text-disabled`, filled
rest `grey-700` (AA on the tint). Menu: Popover paper (`--ok-shadow-dropdown`), at least the
field's width (`--_ok-select-width`, CSSOM) unless `autoWidth`; options are MenuItems (selected
semibold + `--ok-action-hover`). Chips: the trigger wraps them (`display: flex`, 4px gap).

## Responsive behavior
Intrinsic: the field takes its value's width (a FormControl `fullWidth` stretches it); the value
truncates with an ellipsis (chips wrap and the field grows). The menu stays 16px inside the
viewport and scrolls when long (Popover).

## States / Behavior
Core `createSelectController(root, { isOpen, isInert?, autoWidth?, onOpen(focus), onClose(reason),
onPick(option) })` reports intent; owners keep the value and the open state. Single: a pick
replaces the value and closes (`select`), focus returns to the trigger. Multiple: a pick toggles,
the list stays open. Escape / outside press close through the popover controller. Disabled
(`aria-disabled`) and read-only (`aria-readonly`) triggers don't open. HTML runtime `select`:
renders the trigger's content on change (single: a copy of the option's content; multiple:
chips from `template[data-ok-select-chip]` or the options' texts joined with ", "; empty +
`data-ok-display-empty`: the empty option or `template[data-ok-select-placeholder]`), writes
`aria-selected` / `data-ok-selected`, a checkbox's `checked` inside an option, and the hidden
input. A button `[data-ok-select-open="<trigger id>"]` opens it.

## Keyboard
| Key | Action |
|---|---|
| ArrowDown / ArrowUp / Enter / Space / Alt+ArrowDown (closed) | Open on the selected option (else the first) |
| Home / End (closed) | Open on the first / last option |
| Printable character (closed) | Open on the first option after the selected one that starts with it |
| ArrowDown / ArrowUp (open) | Next / previous option, wrapping (MUI MenuList) |
| Home / End (open) | First / last option |
| Printable characters (open) | Typeahead (500 ms buffer; a repeated letter cycles) |
| Enter / Space (open) | Pick (multiple: toggle) |
| Escape | Close; focus to the trigger |
| Tab | Close (prevented, MUI); focus to the trigger |
Disabled options and subheaders are skipped.

## Accessibility
Select-only combobox (WAI-ARIA APG) with MUI's roving focus: the trigger is
`role=combobox` + `aria-haspopup=listbox` + `aria-expanded` + `aria-controls`; the list is
`role=listbox` (`aria-multiselectable` with multiple) of `role=option` with `aria-selected`.
Name: `labelId` (`aria-labelledby`) or `aria-label`. States on the trigger: `aria-invalid`,
`aria-required`, `aria-disabled` (tabindex -1), `aria-readonly`. Subheaders are
`role=presentation`. Checkboxes inside options are `inert` (the option is the control). A disabled
Select's InputLabel is inactive text (exempt from contrast, like TextField's).

## Events / API
HTML: `ok:select:change` (cancelable, `{ value }`: string, or string[] with multiple) before the
value changes; `ok:select:open`; `ok:select:close` (`{ reason }`: `escape` · `backdrop` · `select` ·
`tab` · `toggle` · `api`). Instance: `{ value, setValue(value), isOpen, open(), close() }` (a native
select's instance reads and writes the `<select>`). React: `onChange(value)`,
`onOpenChange(open, reason)`.
