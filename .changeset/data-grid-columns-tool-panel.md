Data grid: `columnsToolPanel` (HTML `data-ok-columns-tool-panel`) turns the Columns panel into a tool panel: a column search, **Show all**, **Hide all** and **Reset**, a pin menu and Move up / Move down for each column, and **Row groups** and **Values** sections outside pivot mode. Nine `columnsManagement…` locale keys in every pack. The Column options story adds a Columns tool panel example.
