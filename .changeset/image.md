Add the Image (`Image`; HTML `span[data-ok-image]` and the `image` runtime): a picture with native lazy loading, a placeholder until it loads, an appear effect (`blur`, `opacity`, `black-and-white`, `none`), aspect ratios, `fit`, `position`, dark or color overlays, `visibleByDefault`, `placeholderSrc`, `srcSet` / `sizes`, and an error state that keeps the text alternative. Markdown gets `images="image"` and `imageRatio` to render its pictures as Images.
