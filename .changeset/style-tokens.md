Style tokens (design styles, step ST2): component CSS no longer holds hard-coded design values. New tokens, each with the value the components used before, so nothing changes on screen: radius roles (`--ok-radius-control`, `-control-sm`, `-inner`, `-surface`, `-surface-md`, `-surface-sm`, `-chip`) and a `--ok-radius-2xs` scale step; `--ok-border-width`, `-strong`, `-heavy`; `--ok-line-width-hairline` to `-2xl` for SVG strokes; focus rings (`--ok-focus-ring-width`, `-offset`, `-inset`, `-offset-tight`, `-color`, `-color-brand`); density sizes (`--ok-control-height-*`, `--ok-control-padding-x-*`, `--ok-field-padding-*`, `--ok-item-*`, `--ok-chip-height`, `--ok-tab-height`, `--ok-cell-padding-*`, `--ok-row-height`, `--ok-accordion-summary-height`, `--ok-switch-padding-*`); font roles (`--ok-font-family-label`, `--ok-label-text-transform`, `--ok-label-letter-spacing`, `--ok-typography-<variant>-letter-spacing`) and sizes (`--ok-font-size-2xs`, `-2xl`, `-3xl`, `-quote`, `-code`, `--ok-typography-quote-mark-size`); loader timings (`--ok-duration-spin`, `--ok-duration-progress-*`, `--ok-easing-in-out`, `--ok-easing-progress-1|2`…); and `--ok-icon-stroke`. Renamed (no alias): `--ok-font-family-secondary` is now `--ok-font-family-heading` (`createTheme` key `typography.fontFamilyHeading`, variant family `"heading"`), and the Tailwind theme key `--font-display` (`font-display`) is now `--font-heading` (`font-heading`).
