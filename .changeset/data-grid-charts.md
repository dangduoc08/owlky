Offer every chart type in the data grid's charts integration: pie, donut, radar and scatter join column, bar, line and area. The chart model also sets stacking, value labels, the legend, colors, the height, the line shape, markers, the value axis title, the toolbar, animations and pie angles, and the chart panel gained Stacked, Show values and Legend fields. Pivoted grids chart one series per pivot column, grouped charts follow the filters, and the HTML grid updates its chart through `updateSeries()`.
