Add Timeline, Rating, Slider, TransferList, tree views (SimpleTreeView, TreeItem, RichTreeView) and Autocomplete. Rating is a native radio group with half values, custom icons and a second click that clears. Slider uses native range inputs for single values and ranges, with marks, value labels, vertical orientation and `disableSwap`. Tree views follow the WAI-ARIA tree pattern with multi-select, checkboxes and a `lines` variant. Autocomplete is a combobox built from TextField, Chip and Popover, with free solo, multiple values and `limitTags`. Numeric options now accept exponents, such as `1e-5`.
