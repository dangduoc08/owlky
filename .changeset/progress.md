Add CircularProgress and LinearProgress (indeterminate, determinate, buffer and query variants, every palette color and `inherit`, `size`, `thickness`, `disableShrink`, `enableTrackSlot`, `valueBuffer`). In HTML, the runtime draws values from `aria-valuenow` and redraws when it changes. Option schemas get a `number` kind. Button and IconButton loaders are now a circular progress; the `data-ok-button-spinner` attribute stays, and an empty spinner span still renders.
