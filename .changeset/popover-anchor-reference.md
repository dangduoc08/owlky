Popover: `anchorReference` (`anchorEl`, `anchorPosition` or `none`) with `anchorPosition` (`{ top, left }`; HTML `data-ok-anchor-position="top,left"`), `marginThreshold` (`data-ok-margin-threshold`) and `transitionDuration` (`data-ok-transition-duration`, ms). `anchorEl` and the HTML instance's `open()` accept a virtual anchor (any object with `getBoundingClientRect()`, such as a text selection). New stories: Anchor playground, Virtual element.
