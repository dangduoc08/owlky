Add Typography (`Typography`; HTML `[data-ok-typography]` on any element, CSS only): text in a step of the type scale (`h1`–`h6`, `subtitle1`, `subtitle2`, `body1`, `body2`, `caption`, `overline`, `button`, `inherit`) from the typography tokens, with `color` (palette or text tones), `align`, `gutterBottom` and `noWrap`. React picks the element from the variant (`variantMapping`) unless `component` is given. Core exports `typographyAttributes`, `typographyElement` and the default mapping.
