Chip: link chips. React `href` / `target` / `rel` make the action an `<a>` (`target="_blank"` adds `rel="noopener noreferrer"`), `component` renders the action as another element or a router link with `actionProps`, and a disabled link drops its `href` (`aria-disabled`). HTML: `<a data-ok-chip-action href>`; Backspace / Delete on a link chip deletes it like on a clickable chip. New story "Clickable link".
