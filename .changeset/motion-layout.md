Motion layout animations and shared values (roadmap 5.4, ADR-0062), with Framer Motion's names. Layout (FLIP): `layout` (`true`, `"position"`, `"size"`) animates a Motion to its new place and size with a transform when the page around it changes; `layoutId` makes Motions in different places one element on screen (a new one moves from the box of the one that left); `layoutDependency` (React) measures only when a value changes; `onLayoutAnimationStart` / `onLayoutAnimationComplete`; a `layout` key in `transition` tunes layout animations only; `LayoutGroup` (`id`, `inherit`) animates siblings together. Nested Motions with `layout` keep their shape while their parent scales, and px corner radii are corrected; focused elements keep the focus when their item moves; reduced motion jumps. New option `initial` (`data-ok-initial="false"`) skips a Motion's entrance. `MotionPresence` gets `mode="popLayout"`. HTML: `data-ok-layout`, `data-ok-layout-id`, `data-ok-layout-group` on a container, the `ok:motion:layoutanimationstart` and `layoutanimationcomplete` events, and instance `measure()` / `animateLayout()` for changes the runtime can't see. Shared values: core `motionValue`, `transformValue`, `springValue`, `interpolate` and `bindStyle` (re-exported by both packages); React `useMotionValue`, `useTransform`, `useSpring`, `useMotionValueEvent`, and shared values or the `x` / `y` / `scale` / `rotate` shorthands in Motion's `style`. Scroll progress gets `smooth` (`data-ok-scroll-smooth`): the bar follows the scroll with a spring. Core: `createLayoutNode`, `flushLayout`, `createLayoutGroup`, `measureLayoutBox`, `motionLayoutAttributes`, `readMotionLayout`, `easingFunction`, `cubicBezier`, `springCurve`, and `animate()` option `commit: false`. Motion gets a "Layout" story and docs sections.
