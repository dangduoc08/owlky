DataGrid phase 5: tree data (from paths or a server data source), master-detail panels, row reordering (drag, or Alt + Up / Down on the handle), pinned rows, column groups (multi-level headers), list view, column virtualization, row and column buffers, lazy loading in chunks, `dataSource.updateRow`, a time to live for the data source cache, chips for the `isAnyOf` filter, and CSV and print options as HTML attributes. Wide grids with fixed column widths now render only the columns in view (turn it off with `disableVirtualization`).
