Add the Organization chart (`OrganizationChart`, `OrganizationChartNode`; HTML `ul[data-ok-organization-chart]`): a hierarchy drawn as nested lists with CSS connector lines, with the `react-organizational-chart` line options (`lineHeight`, `lineWidth`, `lineColor`, `lineStyle`, `lineBorderRadius`, `nodePadding`). Wide charts scroll in a Scrollbar.
