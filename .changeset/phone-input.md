Phone input (roadmap 4.25, ADR-0061). React `PhoneInput` renders a text field (`type="tel"`, `autocomplete="tel"`) with a country select in its start adornment (a Select of MenuItems with emoji flags, the name and "AU (+61)"), formats the number as you type with libphonenumber-js and reports its value in international form (`+61298765432`, `""` when empty) through `onChange(value, details)` with `national`, `international`, `country`, `valid` and `possible`. Props follow react-phone-number-input: `defaultCountry`, `country` (fixed: the select is turned off), `onCountryChange`, `international`, `countryCallingCodeEditable`, `countries`, `countryOptionsOrder`, `addInternationalOption`, `limitMaxLength`, `focusInputOnCountrySelection`, `labels`, `locale`, `metadata`; plus `hideSelect`, `defaultValue`, and `validate` / `invalidText` (the error state and helper text after the field is left with an invalid number). Typing `+` and a calling code selects that country; Backspace and Delete skip formatting characters. HTML: `data-ok-phone-input` with `data-ok-country`, `data-ok-default-country`, `data-ok-international`, `data-ok-country-calling-code-editable`, `data-ok-hide-select`, `data-ok-countries`, `data-ok-country-options-order`, `data-ok-add-international-option`, `data-ok-limit-max-length`, `data-ok-focus-input-on-country-selection`, `data-ok-locale`, `data-ok-validate`, `data-ok-invalid-text` on a text field root, parts `data-ok-phone-input-country` and `data-ok-phone-input-flag`; an opt-in `phone-input` runtime (`@owlky/html/phone`, `owlky-phone.js` after `owlky.js`, or `createPhoneInput({ metadata, labels })`) that fills the country list, with `ok:phone-input:change` and `ok:phone-input:countrychange` and `value`, `setValue()`, `country`, `setCountry()`, `details`. Core: `phoneInputOptions` / `phoneInputAttributes` in `@owlky/core`; the model and controller in the new opt-in entry `@owlky/core/phone` (`phoneInputChange`, `phoneCountryDigits`, `phoneDigitsFromValue`, `phoneCountryOfValue`, `phoneValueDetails`, `phoneCountryOptions`, `phoneFlag`, `createPhoneInputController`…), which adds the dependency libphonenumber-js 1.13.15 (MIT) with its `min` metadata. Styles: `phone-input.css` (the bare country select, its divider and flags). `owlky.js` doesn't load the metadata.
