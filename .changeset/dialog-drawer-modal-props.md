Dialog and Drawer: `disableRestoreFocus` (`data-ok-disable-restore-focus`) and `disableScrollLock` (`data-ok-disable-scroll-lock`), through new `restoreFocus` / `lockScroll` options of the core modal controller; React `keepMounted` (default `true`; `false` renders the children only while open). Drawer: `elevation` (`data-ok-elevation`, 0–24) and `transitionDuration` (`data-ok-transition-duration`). Backdrop: `transitionDuration` (`data-ok-transition-duration`). Core adds `drawerStyle` and `backdropStyle`.
