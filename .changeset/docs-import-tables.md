Every component docs page shows an **Import** table in its API reference: the component's per-component entries (`@owlky/react/<name>`, `@owlky/html/<name>`, `@owlky/core/<name>`), its stylesheets and the CDN module that `owlky.js` loads for it. New guides explain loading Owlky from a CDN (lazy modules, `data-ok-preload`, `owlky.mjs`, self-hosting and a strict Content Security Policy) and with a bundler (per-component entries, dynamic imports, Next.js `optimizePackageImports` and stylesheets). The MCP manifest carries the updated guides and API reference.
